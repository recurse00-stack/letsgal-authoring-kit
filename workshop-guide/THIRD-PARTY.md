# 第三方组件与许可范围

本项目的 MIT 许可仅授予本项目原创代码和文档的权利，不替代 LetsGal 引擎、官方 SDK、官方模板或第三方组件各自的许可。

工坊运行程序将 React、React DOM、React JSX runtime 和 `@avg-studio/sdk` 设为外部依赖，由目标宿主提供。审核包和公开源码不包含官方 SDK、node_modules、引擎可执行文件或官方游戏模板；源码映射也必须检查，不能把这些组件的源文件意外内嵌。

构建依赖由 package-lock.json 固定。2026-09-26 检查锁文件声明：Vite、TypeScript、React、Babel、esbuild、Rollup 等依赖及其传递依赖使用 MIT、ISC、Apache-2.0、BSD-3-Clause 或 CC-BY-4.0。它们用于构建时仍适用原许可；这些声明不表示本项目重新授权它们。维护者可在安装后的对应包目录查阅完整 LICENSE、NOTICE 或许可证链接。

官方 SDK 当前分发目录没有随附可据以重新分发整份 SDK 的许可文本；因此仅作为用户从官方渠道取得的本地编译输入，本项目不转发其源码。官方文档用于核对 API；指引正文、示例和界面为独立编写，不复制官方教程全文。

最终程序需检查实际打入的辅助代码与源映射；发现有第三方实现被打入时，应补入该组件要求的版权、许可或 NOTICE。类型检查／最终构建尚未通过时，不能把这一项标记为最终发行物许可审查通过。

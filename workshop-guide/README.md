# LetsGal AI 创作 Skill 包

**这是给 AI Agent 使用的 Skill（技能）包。** 它通过说明文档、规则和辅助资源，指导 AI 按照 LetsGal 工程的实际版本进行创作、编写 JSON、制作插件技能，以及开展 Git 协作和安全操作。版本为 0.1.0，属于独立社区项目。

**它不是安装进引擎后就能直接增加玩法或自动工作的普通插件。** 工坊里的“AI 创作技能 · 安装与协作指引”扩展是本技能包的获取与使用指引入口，提供风险说明、安装说明和提示词生成界面。要让 AI 使用这些技能，还需要把 Skill 包导入你使用的 AI 工具，并在该工具的新会话中启用。

仅在 LetsGal Studio 中安装或启用本扩展，不等于已经给 AI 工具安装 Skill。本包不附带 AI 模型或账号；请自行准备可用的 AI Agent。本指引扩展不会读取作品，也不会自动安装 Skill、修改个人配置或存档。

## 最简单的方法：下载后让 Agent 帮忙（推荐）

1. **从工坊下载完整包并解压。** 在本条目的开源详情中点“查看源码”下载；无需先访问 GitHub，也不需要看懂源码。
2. **把这个文件夹交给你使用的 Agent。** 在具备本地文件操作能力的 AI 工具里打开该文件夹，或告诉它文件夹的位置并允许访问，然后复制下面这段话。
3. **按 Agent 提示完成必要确认。** 完成后开启新会话，让它核对实际加载的 Skill 来源，再开始创作。用户不需要手动输入安装命令。

> 请帮我把这个 LetsGal Skill 包安装到当前 AI 工具，默认使用个人范围。先读包内说明；如果这是工坊扩展完整包，找到 assets/skill-kit.zip，完整解压到一个新的文件夹，再读内层 README.md、MANUAL.md、COMPATIBILITY.md 和风险说明。确认当前工具、实际运行环境和技能目录，安装前说明目标路径；不明确或权限不足时先问我。优先使用包内安装与检查入口，不绕过校验。发现同名技能、个人修改或其他冲突时先停下说明，不自动强制覆盖；保留个人偏好、插件知识、作品和历史备份。完成后报告文件检查结果，并告诉我如何在新会话中验证加载；未验证的项目不要说成成功。

包内的说明是 AI 可直接读取的 Markdown，并提供安装参数、目录适配和检查入口，Agent 可以据此协助安装。**这需要 Agent 有读取本地文件及执行相应安装操作的权限；只有普通聊天功能时，仍需使用下面的图形安装方法。** 远程／云端 Agent 只能处理其有权访问的实际环境，本机文件夹不会自动传到远端。Agent 协助不会取消下列环境要求，也不代表所有客户端都已实测。

## 安装与使用的必要环境

- **使用 Skill：** 自行安装支持 Skill 的 AI 工具，并配置可用模型（云端服务账号或本地模型）。在需要读写作品时，该工具还须具备项目文件访问能力及你授予的相应权限。只下载本包，或仅有普通聊天窗口，不能代替这些条件。
- **Windows 双击安装：** 需要 Windows 桌面环境、可用的 **Windows PowerShell 5.1（`powershell.exe`）**，以及 **.NET Framework 的 WPF／Windows Forms 图形组件**；系统策略须允许运行本包脚本，所选技能目录和用户配置目录须可写。当前 `Install.cmd` 调用 Windows PowerShell，仅安装 PowerShell 7 不能替代该双击入口的依赖。普通个人导入不要求管理员权限。
- **使用 DSH：** 需要启用文件系统技能提供器与技能读取工具，并选择当前 DSH 实际使用的数据目录；安装器不会自动修改 DSH 预设。
- **预览或导出作品：** 还需要你自行安装作品对应版本的 LetsGal Studio。安装本 Skill 不会安装引擎、模型或插件依赖，也不会自动升级引擎。

**普通安装不需要 Python、Node.js、Git 或自行编译。** 只有使用随包附带的可选 JSON 检查器时才需要 Python 3.9+；执行 Git 操作时才需要可用的 Git。macOS／Linux 按手册手动导入，不使用 Windows 安装器。

环境不满足时，可能打不开安装窗口，或文件已导入但 AI 无法使用。**当前没有完整的环境自动检测或自动补装功能；“导入完成”只表示文件导入结果，不代表 AI 客户端、模型和引擎都已就绪。** 请先补齐必要环境；若受组织或系统策略限制，按手册手动导入或联系设备管理员，不为本包关闭安全保护。

## 也可以自己点：Windows 图形安装

**满足以上环境后，不用打开终端或输入命令，按下面四步点击即可。** 请先备份作品和个人配置；技能包安装器不会替你备份整个作品。

1. **从工坊下载。** 在本条目的开源详情中点“查看源码”，下载完整包并解压。打开 `assets` 文件夹，再解压里面的 `skill-kit.zip`。这里的“查看源码”也是完整包下载入口，普通用户下载后无需看懂源码。
2. **双击安装。** 打开刚解压出的技能包，双击 `Install.cmd`（Windows 隐藏扩展名时显示为 `Install`），即会打开图形安装窗口。不要在压缩包里直接双击运行。
3. **选择 AI 工具并导入。** 选择 Codex、Claude Code、DSH、Cursor 或 Copilot。一般保留默认的“个人 · 所有项目”，核对界面显示的位置后，点击“导入到 …”。DSH 如有提示，用“浏览”选择实际的数据文件夹，无需输入命令。
4. **复制提示，开始使用。** 安装完成后点“复制验证提示词”。在你选的 AI 工具中打开作品文件夹，新建会话并粘贴，让 AI 核对是否加载了本技能和当前工程版本，再告诉它你要制作什么。

**安装或启用前，建议暂时停用其他同类 LetsGal／引擎创作 Skill**，保留其原文件和个人特调，避免调度混乱、额外上下文开销和性能下降。安装完成但 AI 没读到技能时，先新建会话并使用上述验证提示，不要反复删除或重装。

技能 ZIP 已随工坊完整包提供，**无需先访问 GitHub**。若工坊下载暂不可用且能够访问 GitHub，可从 [0.1.0 发行页（备用）](https://github.com/recurse00-stack/letsgal-authoring-kit/releases/tag/v0.1.0) 下载 `letsgal-authoring-kit-0.1.0.zip`，解压后交给 Agent，或从本节第 2 步继续。

macOS／Linux 暂无图形自动安装器，按包内 `MANUAL.md` 手动导入；其他平台未做实机验收。更新、卸载、冲突处理、备份恢复和故障排查也见该手册。手册中的可选检查脚本和开发命令不是普通安装的必做步骤。

## 个人偏好与插件知识

- 个人偏好：`~/.letsgal-authoring/preferences/user.md`。
- 插件知识：`~/.letsgal-authoring/plugins/<id>/<version>/SKILL.md`，由用户独立维护；作品的选择记录在 `LETSGAL.md`。

这两部分独立于公共 Skill 包更新。旧版偏好原位保留，公共包更新不会重置个人特调或插件知识。让 AI 为某个插件编写新的 Skill 时，应按上述插件目录和版本组织；个人需求也可以请自己的 AI 修改到个人偏好区。

## 兼容与验证范围

Stable 2.0.0 和 Beta 2.2.0-beta.1 的官方 SDK 均已通过严格类型检查及实际构建，同一源码生成相同程序；扩展清单采用 `^2.0.0`，使用两版共有接口。AI 应按当前工程证据选择版本，不因本包而自动升级引擎或迁移作品。

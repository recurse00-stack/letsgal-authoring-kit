# 接入我的资料与包管理

总工作台汇总主 Skill、插件指南、创作参考与个人资料。每份指南有自己的阅读空间；包管理集中控制 AI 使用和手册展示，安装文件仍保留在各自目录。

## 进入一份指南

在主页进入“主体／Skill Wiki／个性化”，再选择资料空间，或通过全局搜索打开具体段落。创作参考归入个性化。进入后，侧栏只显示当前指南与阅读版本的目录；顶部选择器用于切换空间，点击“主页”回到总览。面包屑按模块、指南、当前页面显示层级。宽屏正文右侧的目录随阅读位置高亮，滚动不会新增浏览记录。顶部上一步／下一步沿当前工作台的实际浏览记录切换页面，保留当前指南与阅读版本；它们不会撤销编辑或包管理保存。

多版本资料可以通过“阅读版本”切换。明确版本的链接直接打开该版本；普通入口沿已有固定选版，只有一个可读版本时直接进入。自动匹配模式下存在多个版本时，先选择要阅读的版本。这里的操作只改变阅读，不会修改 AI 选版。

空间内默认搜索当前指南和阅读版本，也可切换为全部工作台。正文页打印本页，空间首页打印整份指南；主页保留全部可见正文的完整阅读入口。旧章节链接和浏览器前进、后退仍可使用。

侧栏底部显示工作台版本与候选状态，完整修订放在“版本详情”中。

## 打开本机管理

主包安装完成后，在实际用户区的 `workbench` 文件夹双击 `Open-Workbench.cmd`。需要 Python 3.10+；浏览器打开本机管理页面后，从总工作台进入“包管理”。管理服务按需运行，可在页面点击“退出管理”，30分钟无请求也会结束。已有离线 HTML 始终可阅读。

直接打开 `MANUAL.html` 时是离线阅读模式，可以查看保存的手册；启停和选版需要通过上述管理入口保存。仅在浏览器载入一份资料 JSON，不会改变包的使用状态。

## 管理一个包

准备好已安装的包，在列表按名称、ID或类型查找。包卡分别显示 AI 使用和 Wiki 展示。常用操作直接可见，已安装的旧版本及完整修订在“查看详情”中展开；个人包直接编辑正文。

| 操作 | 保存后的结果 | 怎样核对 |
| --- | --- | --- |
| 启用／暂停 | AI 后续按需读取或跳过该包；文件保留 | 查看“AI 已启用／已暂停” |
| 使用版本 | 选择已安装版本，保留当前启停 | 核对版本与修订；切换不会自动启用 |
| 暂停时仍显示 Wiki | 暂停后仍保留手册阅读、搜索和打印 | 查看“Wiki 已显示／已隐藏”并搜索正文 |
| 打开手册 | 阅读对应版本的资料 | 阅读不改变 AI 选版 |

暂停时默认隐藏手册；包管理列表始终保留该包。插件指南默认自动匹配工程实际插件版本，也可固定已安装版本；固定版本与工程不同，AI 会说明差异并查匹配资料。管理资料包不改变 Studio 插件启用状态。

点击后等“已保存”，再核对结果。遇到其他页面修改导致冲突，页面刷新到最新状态后重新选择。连接中断时重新打开管理入口并核对状态，不要连续重复保存。新的启停状态影响后续按需读取，已经进入聊天的内容不会被撤回。

## 可选附属包自动接入

符合[附属包协议](../ADDON-WIKI.md)的包，在明确安装后自动登记并汇总。新式包保留 `addons/<包ID>/state.json`；已有协作包或插件指南通过包外适配登记接入，原版本目录保持不变。更新主包不会自动恢复暂停项，也不自动选择新版本。

给包制作者的[统一接入接口](../PACKAGE-MANAGEMENT.md)包含注册清单、校验和调用示例。兼容包可以自行调用接口完成汇总，不需要为每个包修改主 Wiki。未登记的旧资料沿原入口阅读，明确接入后才纳入包管理。

## 接入我的资料

主包默认初始化[我的个人包](06-personal.md)，首次提供空白要求、记忆和指南，后续安装仅补缺失文件。个人包支持编辑和启停，不提供发行选版。

个人约定可以继续通过 `preferences/wiki.json` 接入，插件手册也兼容原 `plugins/<ID>/<版本>/wiki.json`。原清单格式见 [Wiki schema](../../maintenance/wiki-manifest.schema.json)。需要启停或选版控制的 Skill 包再使用统一登记接口；已有个人偏好正文不因展示而复制成另一份正本。

完整主包可用下面的命令校验或生成新的个人工作台；生成需要 Python Markdown，日常管理已登记包仅需 Python 标准库：

```text
python maintenance/build_workbench.py --user-area "<实际用户区>" --check
python maintenance/build_workbench.py --user-area "<实际用户区>" --output "<新的工作台.html>" --data-output "<新的资料.json>"
```

可以在清单中提供可选 `navigation` 导览：首页简介、推荐入口和文档分组。未声明时按原文档顺序生成，未分组文档保留在“其他资料”。字段和例子见[包管理协议](../PACKAGE-MANAGEMENT.md#为指南提供导览)。

生成后核对包身份、版本、专属目录、正文搜索、跨文档链接和打印。手动生成不会覆盖旧文件或修改使用选择。公共页“载入资料”仅替换当前页面内容，刷新后恢复原快照。

管理操作同时刷新固定的本机总入口；运行工具也可手动刷新：

```text
python workbench/workbench_runtime.py refresh --user-area .
```

含私人资料的 HTML、JSON和打印稿按[本地 Wiki 隐私说明](../../PRIVACY.md#本地-wiki)保存与分享。公共包携带通用接口和合成示例，实际登记留在各自用户区。

# 创作参考

这里收纳独立、可选安装的方法包，覆盖场面、玩法、节奏及扩展界面设计等问题。先明确目标，再选择适用的方法；主 Skill 负责将方案正确实现到工程。

## 准备与提出需求

下载你选择的附属包，按其说明预览和安装。主包只提供接入机制，不附带这些包的正文，也不会自动下载。安装需要 Python 3.10+；主 Skill 本身仍可单独使用。

> 为这个扩展的设置页设计两种组织方案：作者经常调整颜色和位置，其他参数很少改。请读取已启用的相关参考，比较单页分组和分页的取舍，先给方案。

> 按已经确定的分镜编排这一段，保留原来的节奏和镜头选择。

第一类需求可按需读取设计方法；第二类直接进入主 Skill 的实现流程。

## 预期结果与核对

AI 说明参考了哪个包和版本、方法如何服务目标，以及需要你选择的差异。已定方案和作品约定继续有效。实现前核实际引擎接口；演出段、剧情指令、UI 和扩展都按任务选用。

安装后打开用户区 `workbench/MANUAL.html`，在“创作参考”查到对应包、版本和人类手册，也可用主页搜索。正文只放在附属包自己的版本目录中。总工作台将其汇总为阅读入口。

## 启用、暂停与选择版本

新式附属包在 `addons/<id>/state.json` 记录启用状态和选用版本，`addons/INDEX.md` 提供导航。让 AI 按你的要求调用工作台的 `state` 命令；命令和参数见[资料接入](10-workbench-interface.md#可选附属包自动接入)。

- 首次明确安装后启用并选中该版本。
- 安装另一个版本保留原选择；明确切版才改变 AI 选用版本。
- 暂停保留文件和版本，Wiki 只展示条目信息，正文退出搜索。
- 更新主包会重新汇总已登记的包，保留选版、暂停和个人资料。

旧式包仍按原索引使用。改用新安装协议前先确认原有选版和暂停状态；无法解释旧登记时，安装器停止迁移。阅读或搜索不会更改启用状态。

## 各区怎样分工

| 需要查什么 | 去哪里 |
| --- | --- |
| 引擎和 SDK 支持什么、如何正确调用与保存 | 主体 |
| 具体插件的接口、参数与用法 | Skill Wiki |
| 设计思路、可替代方法和完整案例 | 创作参考 |
| 自己的习惯与作品已经确定的约定 | 个性化与作品原文 |

各包的内容范围、来源及适用条件在自己的手册中说明。没有安装某个参考包，仍可使用主 Skill 完成工程任务。

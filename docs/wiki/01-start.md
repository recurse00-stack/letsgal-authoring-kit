# 1. 入门、安装与确认 AI 实际读取

LetsGal Authoring Kit 是给 AI 使用的创作指南，帮助它选择接口、保留已有内容并检查结果。它不包含 LetsGal Studio、AI 模型或 MCP 服务。你仍在自己的 AI 工具中提出需求，在 Studio 中查看作品。

## 准备什么

准备完整解压的本包、能够访问本地文件的 AI 工具，以及作品的备份。只讨论故事可以暂不连接 Studio；实际修改工程还需[确认版本、工程与 MCP](02-connection.md)。Windows 安装器使用 PowerShell 5.1 或 7，无需管理员、Python 或 Node；可选检查脚本才需要 Python 3.9+。

本包版本为 **0.2.9 / 20261111-stable300**。Stable 对应 Studio **3.0.0**，Beta 对应 **2.9.0-beta.1／2.8.0-beta.1**。Skill 版本与引擎版本是两套编号。完整安装包从 [GitHub Release 附件](https://github.com/recurse00-stack/letsgal-authoring-kit/releases)取得。

## 安装一次

1. 在完整解压目录双击 `Install.cmd`，不要在压缩包内运行，也不要单独摘出脚本。
2. 选择工程对应的正式版或 Beta，再选实际使用的 Agent。通常选“个人 · 所有项目”；只给一个作品使用时选“项目 · 仅此工程”。
3. 核对最终目录、所选／已装通道、版本与修订，再导入。目录应为 AI 实际发现 Skill 的位置，不能选 Studio 的程序文件夹。
4. 展开“更多选项”，点击“检查安装”。底部状态栏应显示“检查安装 · 校验通过”，结果框显示“安装文件校验通过”。
5. 打开 AI 的新会话，进行下面的读取核对。文件校验通过只证明文件完整。

安装器仅替换所选 Skill，保留个人偏好、插件资料和旧版备份，不安装或升级引擎。两个位置已有同名 Skill 时先确认实际加载来源；不要随手复制第三份或删除未知副本。

## 怎样确认 AI 真的读了

可以直接发送：

> 请使用 letsgal-authoring，实际读取你发现的 SKILL.md，告诉我加载路径、版本、修订和通道。读取已有的个人偏好，并说明本次任务会用到哪些约定。先只核对，不改工程。

预期得到具体来源及匹配的 metadata，而非“我会使用这个技能”。继续给出一个局部改句任务时，AI 应读取目标原文及相关专题。插件资料的核对见[个人偏好与插件指南](06-personal.md)。不需要让 AI 每次把整份 Skill 或私人文件复述出来。

如果只有安装成功消息、旧会话仍回答旧修订，先新开会话并核实际路径。若新会话也找不到，查[Agent 目录说明](../../COMPATIBILITY.md)，确认该客户端支持本地 Skill、所在环境和发现配置。粘贴指南文字不会赋予文件权限或 Studio 控制能力。

## 首次需求怎样写

> 在“序章”的“车站”片段里，只把售票员第二句改得更简短。先读前后文，保留样式、行 ID 和配音绑定；给我改动前后对照。其他句子不改。

先给工程、位置、目标和边界，AI 可以在授权范围内完成读取、修改与必要检查。尚未决定写入时说“先讨论／先给候选”。已有内容和采用的定稿继续受保护；新写且未定稿的受托草稿可按目标迭代。作品备份独立于安装器的 Skill 备份，见[恢复](07-recovery.md)。

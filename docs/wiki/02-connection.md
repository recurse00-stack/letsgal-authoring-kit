# 2. Stable／Beta、工程身份与 MCP

## 准备什么

确认目标作品、运行中的 Studio 完整版本和已安装 Skill 通道。保留 `-beta.1` 等后缀。引擎身份以“关于”或当前运行实例返回的版本为依据。

| 目标 Studio | 选择的载荷 | 资料范围 |
| --- | --- | --- |
| 3.0.x 正式版 | Stable 3.0.x | 当前正式系列 MCP 工作流 |
| 2.9.x-beta.* | Beta 2.9.x | 嵌套剧情等 2.9 指导 |
| 2.8.x-beta.* | Beta 2.9.x 的兼容路线 | 使用明确保留的 2.8 指导 |
| 2.5.0 | 历史发行 | 使用当时的完整资料与包 |
| 其他／不明／来源冲突 | 暂停工程执行并核身份 | 版本差异需本次明确许可；可继续讨论和只读核对 |

开工检查只在首次工程操作时静默进行，同一实例和任务复用；发现升级、热更、重连或接口差异时才重新核对。不会每轮对话联网查更新，纯讨论不触发。

本包编号从 **3.0.0** 起按引擎系列组织：前两位表示主要适配系列，第三位用于 Skill 自身修复、小功能和同系列适配。当前 Stable 为 3.0.0，Beta 为 2.9.0，并保留 2.8 Beta 兼容路线。

开工比较前两位与实际发行身份。同为 3.0 正式系列时，3.0.0、3.0.1 和不同界面热修复可直接使用对应资料；无需专门查询补丁号或哈希。运行版本为 3.0.0、更新设置选择 Beta 时，仍选 Stable；正式版与 `-beta` 的实际身份分别处理。

主次版本超出维护／兼容范围，或实际发行身份不匹配时，AI 暂停目标执行并向当前使用者说明差异、请求本次范围许可。系列和身份未变即可复用，补丁变化不单独重新询问。来源冲突或连错工程先核对目标。

切换 Skill 不会切换或更新引擎。同一个技能目录只安装一份同名入口；不同版本的作品可以使用各自项目范围，但要核对 AI 的发现优先级。

## 连接到正确工程

按[官方 MCP 接入指南](https://docs.avg-engine.com/manual/overview/mcp)，在目标 Studio 窗口取得该窗口提供的真实连接地址，再配置到 AI 客户端并批准所需连接。网页中的示例地址只作格式参考。不要使用别人截图里的端口，也不要把令牌贴到公开反馈中。已配置连接时先验证，不必重复安装或重注册。

> 请先读取当前 Studio 状态，核对版本、工程名称和 project.id、连接权限、可用工具组及待保存状态。我这次要改的是“星港练习”。若连到别的工程，先停止写入并说明差异。

预期看到来自当前 MCP 返回的身份。多个窗口可能对应不同端点；窗口标题相同也不能代替 project.id。连接成功、获得写权限、一次具体高影响操作获批是不同状态。

## 切换工程与独立窗口

3.0 的 `studio_open_project` 可打开已有工程，**会在当前窗口保存并关闭原工程**；需要新建工程或独立窗口时使用相应的界面入口。需要保留原工程时，应使用目标已有窗口，或明确授权一次新窗口初始化。2.9／2.8 不套用这个 3.0 入口。

切换、重连、长时间等待确认后，AI 应重新读身份、权限和当前内容版本（revision）。旧 revision 是冲突检测依据，不能一直重复使用。

## 遇到差异怎么办

| 现象 | 怎样继续 |
| --- | --- |
| 等待连接批准 | 在目标窗口确认连接；AI 继续可做的只读资料工作 |
| 只读或明确拒绝 | 保持权限边界，先给草稿；不能绕到磁盘或界面强写 |
| 工具没出现 | 定向发现并真实调用状态工具，失败后有限尝试单服务器重连 |
| 有工具却超时，写入结果未知 | 先读目标和操作记录，确定是否已经落地；不要整批重发 |
| 仍无法连接 | 说明已尝试步骤；需要界面兜底时再按任务授权使用 |

没有 MCP 时仍可讨论、制作草稿或维护独立扩展源码。直接离线写工程前，需要正常保存关闭目标工程并确认其他实例已释放。Computer Use 是必要兜底，日常制作优先专用 MCP。

## 查阅：只读版本命令

在完整包根目录运行；不会探测、启动服务或修改工程：

```powershell
python "channels/stable/skills/letsgal-authoring/scripts/inspect_version.py" --studio-version 3.0.0
python "channels/beta/skills/letsgal-authoring/scripts/inspect_version.py" --studio-version 2.9.0-beta.1
```

工程执行检查加 `--gate` 即可，`--studio-version` 填目标实际完整版本。`operation_gate` 的 matched 表示身份匹配，confirmation_required 表示需本次许可，identity_required 表示先查身份。`--update-channel beta` 只记录更新偏好；不改变实际版本判断。

可用参数还包括 `--studio-exe`、`--project-version`、`--channel`、`--sdk`；项目参数只填明确固定的目标引擎版本。`reference_selected`／退出码 0 表示选到资料；`UNKNOWN`／退出码 2 表示缺失、冲突或未登记。资料路由结果与工程操作准入结果分别读取。

# 纯 Skill 发行检查

本产品是制作 Skill，不承担官方引擎全量认证。发布检查针对本次内容和真实声明，未知能力按使用任务补证。

1. 逐项核对 Skill 本体、简易辅助安装、人类手册，记录 changed／verified-unchanged／missing；有缺项不能称完整。
2. 指引、关键示例／参数有资料依据；普通任务不强制加载全部文档或取得无关 SDK。官方公告、样本、声明、有限运行与推断分别说明，冲突或未知标 UNKNOWN。
3. 检查本次更改的实际行为，复用程序未变且仍适用的历史结果。涉及安装程序修改时做对应隔离安装／更新／保留检查；文档修订重点核对路径、命令、相对链接、锚点与 Markdown／HTML 同步，不重复运行全部引擎测试。
4. 保留防误删、恢复、同类 Skill 建议、风险说明、隐私边界及许可证；用户区、旧版本和备份不进入公共包、不自动清理。
5. 新版本按 release-files.json 白名单构建，核对 bundle、校验和 ZIP 内容；stage_publication.py 生成全新暂存。维护源码、自用和实际安装入口同步按当前绑定核对，保留原 Git HEAD／索引。
6. 更新所属 CURRENT、版本清单及验证摘要。明确本地候选和已发布版本，测试按实际版本／范围记录；没有确认的故障不写成发布阻断项。
7. 发行前核对所有公开文字／图文的统一发行者口吻；内部委托、转述与协作旁白留在不公开记录。获得本次具体外部发布授权后才更新 GitHub。源码、tag、Release、附件、匿名下载分别验收；不覆盖旧资产。纯 Skill 工坊 not-applicable。

本页列出0.1.8的内容与发行核验要求；本版渠道结果另见独立发布／下载凭证，旧版凭证保留。原生安装体验、其他 Agent 和未用到的宿主／Beta 能力是补充测试，不能把目录或组件测试写成原生通过，也不要求先测遍才发布这个 Skill。详见 VALIDATION.md。

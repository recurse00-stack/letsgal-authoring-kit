# 社区发行范围与检查

1. 保留资料保护、备份恢复、必要环境、同类 Skill 冲突建议、风险说明及 MIT 许可证。
2. 固定新版本并按 release-files.json 生成核心 ZIP，逐项核对 bundle.json、校验值、文档链接和公开文件隐私边界；不覆盖已发布资产。
3. stage_publication.py 生成全新暂存；核对完整文件集合和差异，防止私人资料进入公共仓库。
4. 安装器或包内容变更后，在隔离目录检查安装、从原版升级、用户资料保留与只读检查结果。
5. 经本次授权发布 GitHub 后，匿名下载最终资产、核对哈希和归档内容。源码、发布与下载分别验收。

三款 Agent 完整模型任务与更新会话、原生 GUI 点击／取消／选目录／缩放、稳定版及 Beta 的剧情／存读档／Windows 导出仍有暂缓项，不得改为全部通过。已有两轮独立 AI 仅为历史合成验收；不为文档调整重复启动。

自动安装器仅支持 Windows，其他平台手动导入。引擎和 SDK 按具体工程证据选择，不随 Skill 自动升级；本包构建不依赖引擎 SDK。

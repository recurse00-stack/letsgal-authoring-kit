# 社区发行范围与检查

1. 保留资料保护、备份恢复、必要环境、同类 Skill 冲突建议、风险说明及 MIT 许可证。
2. 固定新版本并按 release-files.json 生成核心 ZIP，逐项核对 bundle.json、校验值、文档链接和公开文件隐私边界；不覆盖已发布资产。
3. stage_publication.py 生成全新暂存；核对完整文件集合和差异，防止私人资料进入公共仓库。
4. 安装器或包内容变更后，在隔离目录检查安装、从原版升级、用户资料保留与只读检查结果。
5. 经本次授权发布 GitHub 后，匿名下载最终资产、核对哈希和归档内容。源码、发布与下载分别验收。

当前有限Beta原生观察、独立自动化与实际模型任务分别见VALIDATION.md。原生安装GUI点击／取消／选目录／缩放、Stable运行、Beta完整启动／导出、其他Agent完整任务和新版自动发现仍有未完成项，不得改成全部通过。受限环境无法完成的原生操作须记录接口限制；组件事件不能替代鼠标实测。

全面修订须逐项核对 Skill、辅助安装及人类手册，记录 changed / verified-unchanged / missing。维护脚本只验证其明确范围；独立代理的隔离任务不是全部客户端／真实宿主验收。当前纠正以 AUDIT.md 为入口，不把旧 REVIEW 的历史状态当当前。

版本资料工具须验证实际 EXE 完整后缀、Stable/Beta 路由、未知／冲突、SDK 指纹及输入只读；资料选择不能称为宿主运行通过。人类手册的 Markdown 与离线 HTML 随包同步。

自动安装器仅支持 Windows，其他平台手动导入。引擎和 SDK 按具体工程证据选择，不随 Skill 自动升级；本包构建不依赖引擎 SDK。

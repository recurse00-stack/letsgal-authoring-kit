LetsGal 设计参考：制作人的日常 · 使用手册

版本 0.1.0

这是面向有基础演出、事件编排、界面反馈或轻经营设计需求的创作者的独立可选包，十条方法来自对《制作人的日常》0.1.1 源码的研究与归纳。它可以帮助 AI 讨论安排和改稿，不需要在 Studio 安装扩展，也不会修改游戏工程。它是文档型附加包，没有模型权重。创作者可以根据项目需要选择安装，并只参考其中相关方法。

可以用来做什么

  • 演出与转场： 人物站位与留场；用切换说明地点、时间和阶段变化。
  • 界面与反馈： 把注意力留给当前决策；小变化轻提示、大阶段回顾；说明状态和下一步。
  • 事件与经营： 分开进展与闲逛；先有约束再随机；选项写清行动；关系连接到行动；结算回应本轮特点。

每条方法都有适用条件、新写例子和检查点。完整正文在 AI 入口，也可以直接读演出与转场、界面与反馈、事件与经营。这些 Markdown 文件可离线阅读。

先看一个完整例子

可以对 AI 说：“请参考设计附加包，安排一段车站告别。全程静态镜头，不显示好感值；选择时保留人物，让我看见对方反应。先给方案。”

一种合适的安排是：两人在固定画面的两侧，书本的交接成为动作中心；交还者说完后留场；选项出现时对方仍在，选择后用表情与回应表达变化；离别结束再切回可操作地点。无需增加镜头运动、好感条或经营玩法。

也可以只要求“检查这个界面是否让人知道下一步做什么”，AI 只需读反馈专题。若要求纯工程排错、查 API 或执行已确定的修改，就沿主 Skill 完成，不必重新做设计。

个人偏好放在哪里

当前要求、作品约定和个人偏好优先于本包参考。 已有主 Skill 的偏好分区继续使用：个人偏好在实际 AI 用户主目录的 ~/.letsgal-authoring/preferences/user.md，作品选择按主 Skill 使用工程 LETSGAL.md。本包只说明这项关系，不提供另一套偏好文件，不收集或复制其中内容。

安装与加载

解压后可以直接阅读手册和正文；仅打开文件不会安装。安装和调用都针对实际使用本包的 AI 环境进行。

Windows 有 Python 3 时可运行 Install.cmd，先看预览路径，再按提示选择是否安装。命令行运行 python -B install.py 也只预览；明确安装用 python -B install.py --apply。安装器只用 Python 标准库。

  • 当前 Agent 已有主 Skill： 正文进入 ~/.letsgal-authoring/addons/letsgal-design/0.1.0/，在 addons/INDEX.md 增加入口。首次安装登记为仅在相关设计任务按需启用；已有本包的启停状态和选用版本会保留，不自动换成新版。主 Skill 文件与个人偏好正文不被安装器修改。
  • 当前 Agent 没有主 Skill： 正文安装成独立 letsgal-design Skill。默认技能目录来自 CODEX_HOME，没有时使用 ~/.codex/skills；可用 --skills-root 指定别的 Agent 技能目录。只提供设计参考，不补装主 Skill，不提供工程操作能力。
  • 跨环境： 用 --user-root 指定实际 AI 用户主目录；它不是 .letsgal-authoring 目录本身。预览中核对模式、目标、索引变化后再执行安装。

有主 Skill 时，可以对 AI 说：“先按 LetsGal 主 Skill 读取与本次任务相关的个人偏好和作品约定，再从 ~/.letsgal-authoring/addons/INDEX.md 读取已启用的 letsgal-design 选用版本；本次只参考事件与经营专题，帮我设计一个可以自由安排顺序的筹备日。”索引中的暂停状态继续有效。

没有主 Skill 时，可在支持 Skill 的 Agent 中使用 $letsgal-design 或按实际技能入口调用。是否能自动发现取决于 Agent 的加载机制；主包安装器不会为本包自动安装或配置其他软件。本包安装器也不会改写主 Skill，不要求手工合并主包补丁才能阅读和使用这些方法。

安装结果只证明文件状态；新会话里的实际发现和采用要单独确认。需要参考时，让 AI 说明这次读了哪个专题即可，不必每次加载全部内容。

暂停、换版与恢复

有主 Skill 时，在 addons/INDEX.md 的本包条目把状态改为“暂停”，保留文件；恢复时明确改回启用。更新只新增版本，不自动解除暂停、不自动切换已选版本。确认新版本后，再改索引的选用版本。

同内容重复安装返回 UNCHANGED；同版本内容不同、目标有未知文件或索引版本条目被改动时，安装器停止覆盖。先比较与保全已有内容，再决定保留哪个版本。索引修改前的备份位于用户区 backups/letsgal-design/；需要恢复时按其中 paths.json 找到原路径，先比较后恢复。

没有主 Skill 的独立安装按所用 Agent 的 Skill 启停机制管理；遇到不同内容同样先保全。安装器不会自动删除旧文件或管理其他附加包。

依据与验证范围

方法是对源码实现的归纳，例子为本包新写。它主要覆盖轻经营节奏、界面反馈与基础场面；复杂镜头和音画同步需要更多案例与实际预览。来源与范围列明源码版本、定位和研究限制。

本包没有 Studio 参数、游戏变量或存档数据，因此也没有游戏存档迁移步骤。原样例素材与截图未收入包内，本手册不提供模拟的运行截图。安装测试和语义推演的具体范围见 验证说明。

# Beta 2.3.0-beta.1 创作与扩展

仅在目标工程与实际宿主均确认使用 **2.3.0-beta.1** 时读取。2026-09-30 核对[官方 Beta 清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-beta.json)与[发布历史](https://static-lg-studio.cn-gd.ufileos.com/studio/releases-history.json)。清单是功能公告，未给出所有磁盘字段或 API 签名；下列内容不是完整 schema 或宿主实测结果。

| 需求 | 2.3 Beta 资料与制作方式 | 写入前的依据 |

## 最小例子：一段可点击的调查提示

在独立测试工程中准备已有的“资料面板”和“读取线索”方法，在一句旁白的不同文字位置分别配置打开界面与调用方法。先用 2.3 Beta 编辑器配置并保存，再让 AI 比较该句 `content` 及真实动作参数。正常播放，分别点击，确认只触发目标动作、没有多次注册；再检查读取存档后的显示与方法结果。网页链接使用明确用途的 HTTP/HTTPS 地址，不包含凭据。

这只是配置与验收方法，不提供推测的 JSON 或现成资产。当前 [JSON 参考](https://docs.avg-engine.com/reference/script-json)、[对白](https://docs.avg-engine.com/manual/writing/blocks/dialogue)、[历史 API](https://docs.avg-engine.com/extensions/runtime/history)未必同步公告中的全部字段；缺少签名时先查实际 SDK。独立的“打开外部链接”Block 与行内超链接分别判断，不能拿其重放规则替代超链接实测。

## 扩展和导出

从 [AI 扩展指导](https://docs.avg-engine.com/extensions/llms.txt)和[运行时接口](https://docs.avg-engine.com/extensions/api-context)进入，在目标 `sdk/index.ts`、`sdk/sdk-context.ts` 核对历史追加和相关命名空间。记录 SDK 指纹与来源，不把 Beta SDK 复制到稳定版。历史追加参数与数据列表点击动作的完整序列化在本轮资料中保持 **UNKNOWN**，按真实类型／样本补齐，不编造方法名。

官方说明已导出作品需重新构建以应用本版运行时变化。作品构建按具体授权另做；更换编辑器或更新 Skill 都不会自动刷新旧导出游戏。检查皮肤／部位、超链接三种动作、选项路线、重复预览、历史记录、存读档和导出后的行为。Git、备份和场景切换修复公告不替代用户工程验收。

其他 Beta 版本不能仅按大小比较就复用本页；回[通用兼容](../version-compatibility.md)刷新版本依据。完整运行验收仍未完成。

## 本版原生调用证据

2026-09-30，Windows 实际 FileVersion 与 Studio 原生界面均为 2.3.0-beta.1。在官方新建空白工程的合成章节中观察：

| 调用结构 | 本轮原生结果 | 验证入口 |
| --- | --- | --- |
| main → A，无循环 | 主线开头 → A 内容 → 主线后续 | 调试运行与 OP 视图 |
| A → main，main 不回调 A | A 开头 → main 内容 → A 后续 | 原生片段实时预览与 OP 视图 |
| main → main | 两条旁白各播放一次；OP 共4条，无重复展开 | 调试运行与 OP 视图 |
| main → A → main | A 内容播放后返回主线，没有重复主线开头 | 调试运行 |
| main → A，A 自调用 | A 开头／后续各一次，再回主线 | 调试运行 |

下拉可选 main／自身，保存目标 UUID 保留。循环用例表现为回边未展开，不能据此认定所有循环算法或最大深度。官方文档及界面仍声称最多展开30层，与本轮自调用结果不一致。不要依赖自调用实现可条件退出的递归。此证据不覆盖 branch／if／扩展流接口、Stable、独立玩家或导出；其他 Beta 版本需另行核对。

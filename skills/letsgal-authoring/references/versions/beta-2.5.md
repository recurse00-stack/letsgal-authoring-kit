# Beta 2.5：浮动文字、动态模型与构建排错

适用完整版本：**2.5.0-beta.1**。这是历史Beta资料；2026-10-05发布的2.5.0正式版按[独立专页](stable-2.5.md)读取。以下2026-10-04“本轮”均指当时Beta核对，不是正式版证据。2026-10-04核对[官方Beta清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-beta.json)和[发布历史](https://static-lg-studio.cn-gd.ufileos.com/studio/releases-history.json)，两者公告一致；实际Windows EXE与随包SDK常量也声明此版。资料选择和SDK声明已核对，新增功能的原生保存、播放、存读档与导出本轮未实测。其他完整版本回[兼容规则](../version-compatibility.md)，不按版本大小继承结论。

## 先选择AI能完成的部分

AI可读取工程已有对象、核对素材引用、比较保存差异、整理演出步骤和排错结果；能否点击Studio、导入模型或预览，取决于当前工具。没有宿主控制工具时，交付可执行的人工步骤和静态结果，不声称已运行，也不为这些功能寻找未确认的自动化接口。已有2.3／2.4实测保留原版本范围。

## 浮动文字：显示、继续剧情、按ID隐藏

本版公告扩充文字样式与动效，调整等待和历史选项，修复正文／检查器预览问题。基础入口与主动隐藏语义可查[官方浮动文字手册](https://docs.avg-engine.com/manual/writing/blocks/floating-text)。该页使用“阻塞”措辞，本版公告使用“等待结束”；以目标界面和保存样本核对映射，不直接把一个字段名重命名成另一个。

制作地点牌时，先列出文字、出现位置、停留方式、是否等待、是否加入历史、隐藏时机和目标ID。一个可重复的最小路径是：显示地点牌 → 两句普通剧情 → 隐藏这张地点牌 → 一句确认剧情。无限停留时剧情应能继续，不能等待一个不会自然结束的文字；普通限时文字是否等待则按演出需求选。若只希望隐藏一条，使用同一明确ID；空ID按基础手册会影响全部浮字，不作为单条清理的默认。

只在目标版本原生样本已确认时修改其JSON。内容、变量引用、局部样式和块级样式分别保留；缺少本版样本时可以交付文案和配置步骤，不能猜写等待、无限、历史或隐藏字段。正文变量的显示不等于状态已修改，历史收录也不等于跨重启持久化。

需要验证时，从实际入口观察文字出现、剧情推进、指定ID退场及其他浮字是否保留；另核“加入历史记录”的开关结果。编辑后预览仍旧时，先比较磁盘正文、当前检查器对象与两种预览，不以清空块或强制重写全部样式作为刷新方法。卡片／纯文本提示相同不证明保存和运行相同。

## Live2D与Spine：模型实体和角色表情分开

本版公告集中模型管理，补充封面、选择与播放操作。[当前官方动态图像说明](https://docs.avg-engine.com/manual/creating/dynamic-visuals)区分资产中的模型库与角色的表情配置：先导入模型，再把已有模型绑定到角色表情。模型封面或显示名不能替代真实模型ID；模型登记与底层素材也分别管理。

检查Spine时一起核入口、Atlas、纹理与Runtime版本；检查Live2D时从`.model3.json`的`FileReferences`查依赖。缺文件先列出引用链和原路径，不改成普通图片掩盖错误。Live2D Core按官方第三方SDK流程在负责构建的电脑安装，不能塞进公共Skill或随意复制到作品素材中；模型合法来源与第三方运行授权另核。

旧内嵌配置按官方说明可能在打开工程时迁移。先保全工程，在副本比较模型实体、表情引用、动作／皮肤或动作组／表情，再决定修改；不能因为目录出现新模型库就批量删除旧文件。移除实体前先检查引用和界面影响范围；“移除登记”不等于所有入口都可安全删除底层文件。

最小观察路径：模型库播放 → 角色表情预览 → 一句对白或显示立绘 → 切换表情 → 当前任务需要的导出平台。动作、循环、皮肤、头像各自核对；模型预览成功不能替代导出，某台电脑的Core配置也不保证另一台能构建。

## 素材、姿势与撤销

撤销／重做公告针对素材数据操作，不能当作外部文件编辑、删除磁盘文件或Git恢复的全量保证。操作前记录目标对象及当前引用；撤销后重读具体对象和引用，不能只看卡片回来就认定文件恢复。复制素材需检查新引用是否指向预期文件；删除确认应核对具体资源和受影响对象。

头像裁剪可切换姿势，不代表各姿势共享裁剪。皮肤预设、隐藏部位及中景表情尺寸相关修复按同一角色的两个姿势逐项观察，保留共享配置与当前姿势覆盖的区别；不为排错删除所有预设或隐藏设置。前版用法见[2.4专页](beta-2.4.md)，不继承其有限实测为2.5通过。

## 缺资源、镜头与预览差异

构建失败时，利用日志中的使用位置，定位章节／Block、角色、场景或扩展资源的真实引用，再检查文件存在性、大小写、项目相对路径和打包策略。优先恢复合法原资源或修正已确认的引用；删除引用会改变作品，不能为“构建成功”默默删掉内容。基础流程见[官方构建说明](https://docs.avg-engine.com/manual/overview/build)。

章节局部预览提示镜头或幕布遗留时，先比较局部入口和正常前置剧情：是缺少初始化、依赖前一章节状态，还是作品需要明确复位。仅在期望已确定时添加复位步骤，不统一清空镜头／幕布。独立与内嵌预览、文字阴影回填、BGM淡出、旁白间隔后的头像分别观察；公告修复不能直接判定当前症状都已解决。已导出游戏需重新构建才能包含运行时改动，更新Skill不会刷新旧游戏。

## 开发者中心与运营统计

本版公告说明构建时可选择玩家统计，并在开发者中心查看章节、选项和留存。读取到这一能力不表示作品已开启，也不是主Skill安装步骤。先确认当前作品是否需要统计、目标平台、数据处理协议及本地密钥状态；没有明确需求时保持原设置，不替作品开启上报或申请密钥。

统计密钥、账号和玩家数据仅按当前任务处理，不写进公共Skill、示例或发行说明。当前构建手册未提供完整统计参数，本轮也未验证服务端收集／展示：字段、协议版本、平台覆盖、失败行为和SDK入口为UNKNOWN。需要实现时查该版构建界面及开发者中心实际说明，不编造上传API。

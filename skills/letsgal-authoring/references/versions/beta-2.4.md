# Beta 2.4.0-beta.1：差分皮肤与新版Tab

本页仅路由目标工程与实际宿主确认使用 **2.4.0-beta.1** 的任务。2026-10-02核对[官方Beta清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-beta.json)与[发布历史](https://static-lg-studio.cn-gd.ufileos.com/studio/releases-history.json)，均列此完整版本。十三项变化见[累计清单](beta-differences.md#240-beta12026-10-02核对)；公告给出界面与行为方向，没有完整磁盘schema或SDK签名。

## 制作时怎样选择

| 需求 | 本版工作方式 | 写入和验收 |
| --- | --- | --- |
| 差分整套换装 | 在目标差分角色配置部位素材组合及皮肤预设，再在剧本选择 | 先让此版本编辑器保存预设和对白；保留实际ID，不将旧版皮肤对象改名作为迁移 |
| 变量控制部位 | 部位总览检查变量绑定与实际项目变量 | 显示绑定、变量取值和画面效果分别核对；未知绑定字段不猜写 |
| 不同姿势的头像 | 给每个目标姿势配置裁剪，观察头像预览 | 单个姿势的裁剪不代表其他姿势；编辑预览、玩家显示与读档分别判断 |
| 对白角色参数 | 在正文中打开Tab菜单，选择角色／姿势／皮肤及距离位置 | 先确认当前句与连续组的作用范围，保存后重读；名称、结束行为按菜单实际选择 |
| 长按与布局 | 长按Tab保持菜单，松开恢复；需要时调整尺寸／布局／右侧面板显示 | 普通Tab打开结果不能算长按通过，不把键位工具限制写成引擎故障 |
| 扩展更新问题 | 核对项目实际启用的扩展版本与发行物，读取同步失败提示 | 保全源码与旧版；公告修复不能代替目标插件运行，也不自动重试不明事务 |

## 最小换装练习

在隔离副本使用原创的两种服装色块与一个差分角色，保留原素材。先配置同一姿势的两个素材组合，保存皮肤预设；在两句对白中分别选择预设，并在第三句恢复自动选择。保存后比较该角色与章节的实际引用，不能把显示名填成ID。运行三句，检查服装变化、其他部位、头像与返回自动的表现。若另做属性变量换装，单独核对变量取值与优先关系。需要导出／存读档时再测试该入口。

这是制作与验证路径，未取得目标样本的部分仍为UNKNOWN，不能直接生成一份猜测的角色JSON。复制或删除预设、删除姿势、预制包导入导出使用副本，保留素材原件和恢复记录。

## 本版证据范围

2026-10-02 已核对实际FileVersion、欢迎页及安装资源中声明2.4.0-beta.1的SDK。原生隔离工程保存的空白旁白可以没有content；自动检查提示复核而不改写，新生成文本仍要求数组。原生普通Tab可打开，界面显示名称／结束行为与八个尺寸调整点；这只证明入口和可见控件，不证明长按、全部参数或玩家效果。空差分角色的新建／命名／复制预设已保存：differentialPortraitAssembly.skinPresets为数组，每项有id/name/selections，复制项得到不同UUID，空素材的selections为对象；不能据此推断带素材、变量、头像或运行效果的完整字段。完整包的HOST-VALIDATION.md记录本次有限观察；安装后按目标工程补充证据。

旧[2.3专页](beta-2.3.md)中的main、超链接、变量、history API、导出和读档仅证明2.3.0-beta.1；本页不据版本递增继承这些结论。2.4 SDK的API兼容按当前扩展单独查证。Stable与其他Beta仍分别取证。

更新Skill或编辑器不会刷新已导出的游戏；官方要求重新构建才能应用运行时变化。未知工程版本、通道冲突或其他完整版本回[兼容规则](../version-compatibility.md)处理。

# Stable 2.0 系列资料

适用于已确认的 2.0.0／2.0.1 宿主。这里只选择资料，不承诺完整运行兼容。

2026-09-30 查阅：官方 [Stable 下载清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-stable.json) 的 Windows 条目仍为 2.0.0；[发布历史](https://static-lg-studio.cn-gd.ufileos.com/studio/releases-history.json) 已列出 2.0.1。二者不是同一份最新版本证据，选择按实际安装／运行实例，不凭此差异自动升级。

2.0.0 的蓝图、资源预加载、分层立绘等能力按[章节调度](https://docs.avg-engine.com/advanced/chapter-scheduling)、[JSON 参考](https://docs.avg-engine.com/reference/script-json)及目标保存样本使用。蓝图需确认当前工程已启用。2.0.1 记录修复扩展读取数据集合等问题，官方要求已导出作品重新构建以应用修复；本 Skill 不自动构建或发布作品。

不要套用 [2.3 Beta 新能力](beta-2.3.md)的超链接、差分编辑或历史追加契约。稳定版 SDK 无对应声明时保留原实现。其他稳定版本走[通用兼容](../version-compatibility.md)，先刷新该版依据。

静态检查、目标宿主预览、存读档和平台导出各自验收；本包未完成双宿主实测。

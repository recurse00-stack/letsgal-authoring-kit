# 正式版到 2.3.0-beta.1 的累计差异

2026-10-01 重新读取[官方发布历史](https://static-lg-studio.cn-gd.ufileos.com/studio/releases-history.json)、[Beta 清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-beta.json)与[Stable 清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-stable.json)。Windows Beta 清单为 2.3.0-beta.1；Stable 清单仍为 2.0.0，历史另列 2.0.1。这里以正式版 2.0.0／2.0.1 为资料基线，列出之后三个 Beta 的公告，不用清单替代目标工程实际版本。

据用户于 2026-10-01 转述的官方答复，官网文档只更新正式版，Beta 尚未同步。答复原文、官方链接与答复日期未取得；这是用户转述，不伪装成公开公告。正式版网页可作基础资料，Beta 新字段、SDK 签名和行为分别查目标版本证据。

## 怎样读状态

- 下表覆盖 38 个官方公告顶层条目：2.1 六项、2.2 六项、2.3 新功能十一项／优化八项／修复七项。一项可包含多个变化，不是 38 个新功能或验收通过数。
- **公告：38 项均已获取。** 表中的“需要的证据”是具体使用该能力时的核对方向，不是 Skill 发布前必须跑完的清单；已有有限样本／运行分别注明。
- 本轮取得 N05／N06／N08 的有限原生保存样本及 N11 历史 API 的官方初始化 SDK、构建与运行证据；未取样的字段／接口保持 UNKNOWN。纯界面、性能和修复操作不强加不存在的 SDK 前置。
- 只看到公告不能直接生成新字段；拿到样本仅确认该保存形式，拿到 SDK 声明仅确认该声明。预览、玩家、存读档、重启和导出分别判断。
- 这些是各版首次公告的变化；2.3 重做了部分早期编辑方式，不保证 2.1／2.2 的界面原样保留，也不单凭 2.3 公告认定更早版本缺少相关基础能力。只按当前任务读相关条目。

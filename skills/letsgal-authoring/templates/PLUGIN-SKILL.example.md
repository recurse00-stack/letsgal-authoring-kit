# 插件 Skill 编写模板

这是公共写作模板，不是一个已安装插件。分析真实插件后在用户区 plugins/<插件ID>/<版本>/SKILL.md 新建实际文件；不要把此模板原样登记为已验证能力。用户已有 Skill 应保全后局部修改。

实际 SKILL.md 以 YAML frontmatter 开头，填入独立名称和明确适用场景，例如：

```yaml
---
name: letsgal-plugin-example
description: 根据实际插件填写功能、适用请求和限制。
metadata:
  plugin_id: 按真实清单填写
  plugin_version: 按清单或源码提交填写，未知则明确标记
---
```

正文按需要包含：

- 来源：插件说明／源码位置、核对日期、对应版本或提交；保持可追溯，不复制账号或密钥。
- 适用工程：目标 Studio／SDK／通道、必须已启用的依赖；未知项明确写未确认。
- 功能入口：插件实际提供的界面、方法或设置；区分插件能力和引擎自带能力。
- 参数和示例：只写有依据的字段、类型、必填条件、返回或状态影响；例子使用合成内容。
- 使用流程：先核对当前项目的启用状态与版本，按任务读取必要参考文件。
- 保存与兼容：稳定 ID、存档字段、版本差异和已知限制，不默认替用户升级或迁移。
- 验证状态：分别记录静态分析、构建、宿主加载、预览／存读档／导出；未做的明确写未验证。
- 维护边界：由用户独立维护；本体 Skill 更新不覆盖；未经授权不修改插件代码或其他作品。

较长的接口资料放在同目录 references/ 中，并从 SKILL.md 按任务链接。插件索引只需登记 ID、版本、相对入口、来源、验证状态，保留已有条目；项目的实际启用选择放 LETSGAL.md。

# LetsGal 项目约定（按实际项目修改后再采用）

此文件是模板；安装技能不等于采用以下目录或流程。可以让 AI 结合现有工程生成自己的 LETSGAL.md。

- 工程位置与范围：由用户指定，禁止扩展到其他作品。
- Studio 完整版本／发布通道：unknown；核对“关于”或安装包后填写 stable／beta，保留后缀和事实来源。
- SDK／相关扩展版本：unknown；按当前工程的实际 SDK 核对，不复制其他版本的 SDK。
- 插件选择：按当前项目实际依赖／启用状态记录插件原 ID、版本和对应插件 SKILL.md 入口；未启用的不视为可用，不自动选择资料库中的最新版本。
- 已确认可用能力与调度方式：unknown；记录本次用到的功能及依据，不默认蓝图或 Beta 功能。
- 升级策略：沿用当前作品版本；是否升级由用户决定，禁止因 Skill 更新自动迁移工程。
- 创作目标与当前阶段：填写本次作品方向，标明讨论／制作／测试。
- 已确认设定入口：填写现有设定文档；候选方案另列。
- 文风、语言、命名、资源目录：依用户习惯填写。
- 玩家操作与目标平台：填写实际目标。
- Git：现有仓库、分支规则、是否按阶段提交、推送授权范围；未采用 Git 可写不适用。
- 素材与存档备份：填写实际备份位置与恢复方式，不把 Git 当作全部备份。
- 协作：章节／共享文件负责人、编辑器自动保存与同步约定。
- 验证：指定需要的静态检查、预览、存读档与导出平台。
- 本地可用工具：列实际已连接工具；官方 MCP 若尚未配置则写未配置。
- 交接位置：优先复用项目现有文档。

安全底线：保存用户未提交内容；独有数据删除、不可逆覆盖和外部发布按具体授权执行。调整流程不代表自动授予这些权限。

# 扩展界面设计参考

这是 LetsGal Authoring Kit 的可选附属包，帮助你和 AI 设计扩展设置页、参数检查器及编辑预览。它提供可改编的方法与案例；主 Skill 负责工程实现，具体插件指南负责该插件的参数与用法。

## 从一个需求开始

准备扩展要解决的问题、已有参数和作者常做的操作。例如：

> 这个提示卡扩展有文本、位置、颜色和显示时长。请按我的现有参数，比较单页分组和分页两种方案，说明各自适合什么情况，先不要改代码。

预期得到页面结构、字段组织、预览内容和主要取舍。核对常用操作能否顺利完成、已有选择是否保留，再决定是否实施。

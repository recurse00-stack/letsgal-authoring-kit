LetsGal 设计参考：制作人的日常 · 使用手册

版本 0.1.1

这是面向有基础演出、事件编排、界面反馈或轻经营设计需求的创作者的独立可选包，十条方法来自对《制作人的日常》0.1.1 源码的研究与归纳。它可以帮助 AI 讨论安排和改稿，不需要在 Studio 安装扩展，也不会修改游戏工程。它是文档型附加包，没有模型权重。创作者可以根据项目需要选择安装，并只参考其中相关方法。

可以用来做什么

  • 演出与转场： 人物站位与留场；用切换说明地点、时间和阶段变化。
  • 界面与反馈： 把注意力留给当前决策；小变化轻提示、大阶段回顾；说明状态和下一步。
  • 事件与经营： 分开进展与闲逛；先有约束再随机；选项写清行动；关系连接到行动；结算回应本轮特点。

每条方法都有适用条件、新写例子和检查点。完整正文在 AI 入口，也可以直接读演出与转场、界面与反馈、事件与经营。这些 Markdown 文件可离线阅读。

先看一个完整例子

可以对 AI 说：“请参考设计附加包，安排一段车站告别。全程静态镜头，不显示好感值；选择时保留人物，让我看见对方反应。先给方案。”

一种合适的安排是：两人在固定画面的两侧，书本的交接成为动作中心；交还者说完后留场；选项出现时对方仍在，选择后用表情与回应表达变化；离别结束再切回可操作地点。无需增加镜头运动、好感条或经营玩法。

也可以只要求“检查这个界面是否让人知道下一步做什么”，AI 只需读反馈专题。若要求纯工程排错、查 API 或执行已确定的修改，就沿主 Skill 完成，不必重新做设计。

个人偏好放在哪里

当前要求、作品约定和个人偏好优先于本包参考。 已有主 Skill 的偏好分区继续使用：个人偏好在实际 AI 用户主目录的 ~/.letsgal-authoring/preferences/user.md，作品选择按主 Skill 使用工程 LETSGAL.md。本包只说明这项关系，不提供另一套偏好文件，不收集或复制其中内容。

安装与总 Wiki

解压后可以直接阅读手册和正文；仅打开文件不会安装。本包可独立选择，主 Skill 默认安装不附带本包。

安装需要 Python 3.10+，接收端只用标准库。Windows 运行 Install.cmd，先看预览，再决定安装。命令行 python -B Install.py 默认只预览；追加 --install 才应用。用 --skills-root 指定实际 Agent 的技能根目录，--user-area 指定实际 .letsgal-authoring 用户区；后者直接指向用户区，不是用户主目录。

  • 已有主 Skill： 载荷进入 addons/letsgal-design/0.1.1/，状态登记在 addons/letsgal-design/state.json，索引导航指向该状态文件。首次安装选用本版；已有启停状态和选用版本继续保留。
  • 已有支持附属包协议的总 Wiki： 安装后自动刷新用户区 workbench/MANUAL.html，在“创作参考”中打开本包手册、设计专题、来源及验证说明。无需手工编辑主页面。
  • 尚无总 Wiki： 安装结果标明待接入，仍可使用独立手册。以后安装支持该协议的主包时，总入口会汇总已登记资料。旧主包的静态页面不会自行变成新版总 Wiki。
  • 没有主 Skill： 载荷进入所选技能目录中的 letsgal-design，按 Agent 的 Skill 机制调用。以后接入主包，需明确重新运行安装器并处理原独立入口，避免重复使用。

主 Skill 只在任务相关时读取已启用、已选用的本包版本；查 API、排错或照既定方案施工不需要先加载设计方法。可以对 AI 说：“按主 Skill 读取相关个人偏好和作品约定，再用设计参考包的事件与经营专题，帮我设计一个可自由安排顺序的筹备日。”

独立模式可使用 $letsgal-design 或实际 Agent 提供的调用入口。文件安装和 Wiki 接入不等于 Agent 已在新会话中发现并采用；第一次使用时让 AI 读取入口及所需专题即可。

暂停、选版与更新

新协议以 addons/letsgal-design/state.json 的启停和选版为准，索引只作导航。使用用户区 workbench/workbench_runtime.py 的 state 命令，将 --id 设为 letsgal-design；--enabled no 暂停，--enabled yes 恢复，--version 选择已安装版本。命令需同时指定 --user-area。更改后自动刷新总 Wiki；暂停包只显示名称、版本等信息，正文不被读取或搜索。

重复安装同一载荷只核验，不重复覆盖。安装新版保留旧版与原选版；明确追加 --select 才选用本次版本，追加 --enable 才解除原暂停。独立模式按所用 Agent 的启停机制管理。

同版本文件不同会停止并要求比较；确认替换才追加 --replace，原目录完整保留到用户区备份。不要用替换选项绕过来源或差异检查。真实作品、个人偏好和其他包不随本包替换。

从旧格式 0.1.0 接入

旧包将七个 Skill 文件直接安装到版本目录，以 addons/INDEX.md 文字记录启停与选版。新载荷增加手册和 Wiki 库，安装到独立的 0.1.1 版本目录。本版不提供旧文字索引的自动迁移：检测到旧索引提及本包且没有新导航块时，即使指定 --replace 也会在写入前停止，原目录和索引保留。

已经使用旧格式的创作者可以继续使用原包；需要总 Wiki 接入时，先让 AI 核对并保全原索引、旧载荷、个人及作品约定，再准备明确保留启停和选版的迁移方案。不要删除旧条目来跳过检查，也不要把 --replace 当作状态迁移。后续迁移必须核对新状态文件与总 Wiki；恢复时按备份记录比较和恢复原目录、索引及状态。

依据与验证范围

方法是对源码实现的归纳，例子为本包新写。它主要覆盖轻经营节奏、界面反馈与基础场面；复杂镜头和音画同步需要更多案例与实际预览。来源与范围列明源码版本、定位和研究限制。

本包没有 Studio 参数、游戏变量或存档数据，因此也没有游戏存档迁移步骤。原样例素材与截图未收入包内，本手册不提供模拟的运行截图。安装测试和语义推演的具体范围见 验证说明。

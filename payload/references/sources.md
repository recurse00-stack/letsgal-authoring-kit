# 来源与适用范围

本包是社区整理的可选设计参考，适用于 LetsGal 扩展的设置页和方法检查器。布局方法可以跨版本借鉴，具体组件和 SDK 接口以目标宿主为准。

主要参考官方工坊“Studio 组件包演示”1.0.0，ID `avg.official.studio-ui-showcase` 的 README、Studio 入口、设置页及提示卡／评分检查器源码。该演示用于向扩展开发者展示组件组合，并非可直接用于游戏的成品。查阅时在工坊按 ID 定位对应版本，也可通过官方 MCP 的工坊源码读取接口核对。

本包归纳了分组、局部预览、自动表单与自定义控件组合等方法，并另写提示卡案例；未分发演示源码或素材。案例字段用于说明组织思路，实际字段以所做扩展为准。这里的设计取舍由本项目整理，官方 API 契约由官方资料维护。

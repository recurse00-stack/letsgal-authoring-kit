# LetsGal 设计参考：制作人的日常

给需要基础演出、事件编排、界面反馈和轻经营设计方法的创作者提供一份可改编的参考。依据 LetsGal Studio 工坊范例《制作人的日常》0.1.1 源码提炼，包含 **3 个专题、10 条方法**，配有来源定位、适用条件和新写例子。

这是社区整理的独立可选 Skill 附加包。创作者按项目需要选择安装，主 Skill 的工程能力与本包的设计参考分别使用。

## 包含内容

- **演出与转场：** 人物关系与站位、留场连续性、切换所表达的变化。
- **界面与反馈：** 当前决策需要的信息、小变化与阶段回顾、操作状态与下一步。
- **事件与经营：** 正式进展与自由闲逛、有约束的随机、行动选项、关系带来的行动、回顾本轮特点。

方法均可按作品改编。样例的固定日程、奖励数值、两选结构和漫画风格只是具体案例；当前使用者的要求、个人偏好与作品约定优先。

## 开始使用

解压后阅读[使用手册](USER-GUIDE.md)或[离线 HTML](USER-GUIDE.html)。Windows 用户准备 Python 3 后可运行 `Install.cmd`，先查看安装预览，再选择是否应用。

已有 `letsgal-authoring` 时，安装到实际用户区的版本化附加包目录，并登记索引；主 Skill 和个人偏好正文保持原样。没有主 Skill 时，可独立安装到所用 Agent 的技能目录。具体参数与调用提示见手册。

安装只提供设计资料，没有模型权重，也不安装《制作人的日常》扩展。实际工程操作仍由主 Skill 和创作者授权的工具完成。

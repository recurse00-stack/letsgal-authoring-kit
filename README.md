# LetsGal 扩展界面设计参考 0.1.0

可选附属 Skill：帮助设计扩展设置页、方法检查器与编辑预览。独立安装，接入主包 Wiki 的“创作参考”，不随主包捆绑。

先运行 `python Install.py` 预览，再运行 `python Install.py --install`。需要 Python 3.10+；[完整手册](payload/docs/README.md)与[离线 HTML](payload/MANUAL.html)说明安装、暂停、切版及设计练习。

本包维护设计方法。引擎／SDK 的正确调用由主 Skill 和官方资料维护。来源与范围见[来源说明](payload/references/sources.md)。

本包独立发行；与主包一起使用时，主包 3.0.4 起提供自动 Wiki 接入。

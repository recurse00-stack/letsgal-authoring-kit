# 创作参考的按需读取

需要比较演出、叙事、玩法、节奏或扩展界面设计方案时读取本页。执行已定方案、API 查询和工程排错直接使用操作专题。

1. 按[偏好与作品选择](customization.md)读取当前相关约定，复用已经读取且仍有效的内容。
2. 从实际用户区 `addons/INDEX.md` 定位相关包。新式条目指向 `addons/<id>/state.json`：核 `enabled`，按 `selected_version` 及其 `versions` 记录读取。旧式条目继续按索引明确登记的启用状态和选版处理。暂停跳过，冲突或缺少选版时先核资料，不按目录排序取最新。
3. 读取选中版本的 `SKILL.md` 及当前专题。嵌套包可以按确认路径读取，无需出现在全局 Skill 列表中；不重复安装。用户指定只比较另一版本时保留原选版。
4. 将设计方法用于提出可选方案，说明与目标的联系和取舍。用户已定方案继续执行，方法不限定必须采用某个组件、演出段或插件。
5. 进入工程实现时回到主 Skill 的相应操作专题，核实际宿主和接口。设计建议与实现契约分别维护。

可选包例子：`letsgal-design` 提供场面、反馈和事件方法；`letsgal-extension-design` 提供扩展设置页、检查器和预览表达的设计参考。只读取已安装、启用且与任务有关的包。具体插件参数查[插件知识](plugin-skills.md)，SDK 查[扩展](extensions.md)。

新式包的状态同时供 AI 与 Wiki 使用。安装、切版或暂停后由安装工具刷新用户区 `workbench/MANUAL.html`；阅读页面不会改变状态。主 Skill 更新保留附属包和个人资料。

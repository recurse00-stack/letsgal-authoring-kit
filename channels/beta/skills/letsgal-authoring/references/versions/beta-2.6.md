# Beta 2.6：官方 MCP 按能力启用

适用精确版本：2.6.0-beta.1。2026-10-08 核对实际 EXE FileVersion、官方 MCP 状态返回与[官方接入页](https://docs.avg-engine.com/manual/overview/mcp)。该页明确 MCP 从此 Beta 提供；其他版本不凭数字推定接口相同。版本资料路由不会检测或启用 MCP，也不代表 SDK 和全部宿主能力兼容。

本页聚焦本次 MCP 工作流更新，不宣称已全面复核 2.6 的所有新增功能。已有剧情、变量、JSON、扩展、个人偏好及插件知识继续使用；具体功能依据目标样本、该版官方资源与相关 SDK。2.5.0 的实测保留原版本归属，不转记为本版通过。

- 当前官方 MCP 可用且身份／权限匹配：按 [MCP 工作流](../mcp-workflow.md) 优先操作 Studio 内存中的工程。
- 未启用／未配置 MCP：保留原有文件与原生界面流程。直接编辑工程文件前关闭目标工程；无需为使用 Skill 配置 MCP。
- 待批准、只读、工具组未开放或断线：处理对应缺项；不绕过权限，也不写活动工程文件。
- 官方快速指南和专题资源由该实例提供，优先按实际 schema 调用；版本未知的其他 Beta 留在 UNKNOWN，仍可继续无版本依赖工作。

已经取得的证据仅包括连接、状态、工具目录、静态资源和先前获批后的只读工程目录；未在本次更新中实际执行 MCP 工程写入、撤销、外部编辑提交／回滚、调试或玩家验收。main、If、存档和 SDK 的旧版结果不能自动沿用为 2.6.0-beta.1 结论。

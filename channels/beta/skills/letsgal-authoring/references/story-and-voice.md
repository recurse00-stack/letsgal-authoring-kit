# 剧情、语言与配音

按任务读取本页对应部分；工程读写沿用 [MCP 执行](mcp-workflow.md)。内容与录音、显示语言与音频语言分别验收。

## 剧情、变量与流程

先区分普通章顺序、前处理和高级调度，保留当前入口。片段调用、选项和 If 的目标限同章；普通被调用片段结束后回到调用处，章末不是整个作品结束。蓝图节点位置和连线外观不改变运行语义。

变量分别核 key、类型、初值与槽位／共享／启动重置语义；回标题、读档和预览刷新不等于全新启动。选项的跳转与变量操作模式分开，赋值与增量分开；不要把“加 1”写成“设为 1”。变量分组是编辑组织，不改变 key 和持久化；当前 MCP `var_edit` 没有分组写入操作。

If 不是持续监听，历史回放可能复用既有判断；需要按新状态判断时设置新的独立判断点，不通过重写旧 ID 清缓存。条件方法尽量只查询，副作用另设动作。当前 `callFragment` 契约是同章子流程、结束返回；自调用在转换期最多静态展开 30 层，不是能靠运行时条件退出的递归。循环菜单优先按实际调度设计，不依赖递归截断。字段与检查器限制见[JSON](json.md)。

## 多语言配音

原声绑定、音频语言、语音表和单句覆盖分别核对：

1. 常规多语言录音先绑定原声，再核语音表中相同 key 的各语言文件；没有目标语言时按引擎规则回退原声。
2. `voice_edit.assign_locale` 给音频标语言，null 表示原声；`set_voice_key` 的 null 使用去掉语言目录和扩展名后的派生键。以当前 schema 和实际路径核对，不能把改标签当作绑定对白。
3. 单句音频操作未指定 locale 时处理原声槽；指定 locale 是这句的语言覆盖，优先于语音表。清除覆盖恢复表匹配／原声回退，不是设为静音。
4. 自动匹配先 dry run，带当前 baseRevisions，检查实际命中、已由语音表匹配而跳过的句子及未匹配项；不能因跳过就覆盖已有配音，也不为缺音频擅自生成译文。
5. 写后核稳定句子 ID、其他语言保留、目标语言试听与缺音频回退。文字翻译和录音更新各自验收。

## 本地化与语音识别

`l10n_read` 按 config／rows／names／coverage 读取实际范围；当前 names 包含已登记角色的显示名变体和正文中手填的说话人名称，不沿用“姓名不可本地化”的旧结论。UI 文案、章节名和游戏标题不能由对白翻译表的覆盖率推定已翻译。写入前核目标语言、稳定行 ID、源文本哈希与当前状态，保留其他语言。过期 source／sourceHash 返回 SOURCE_CHANGED 时重新读取，不能无条件覆盖。使用 `preview_control.set_locale` 前读取并记录当前预览语言，校对后恢复该原值；仅原值为 default 时才设回 default。恢复前核对工程及当前语言：若已被用户或其他操作改动，保留新值并说明，不用旧记录覆盖；原值无法确认时先读取，不猜作 default。这是临时预览语言，不是项目默认语言。语音回退另验。

`voice_transcribe` 使用宿主本地模型；仅指定本次素材，不用 scope=all 重识别其他录音。启动返回后通过 `asset_list(view="voice")` 核运行与文本。模型文件存在、ready、任务启动和识别完成分别判断。2.8.0-beta.1 已观察到模型 ready 后仍 BUSY 且无任务启动；此现象也出现在单机，不能只归因于协作或模型未加载。遇到同类情况核面板、队列和错误，有限重试后保留未完成；不无限轮询或自动下载替代服务。cancel 会停止 Studio 当前所有识别任务，不能为清理本次测试误停他人任务。需要配音时可直接绑定已有合法音频，识别失败不意味着音频不能使用。

## 游戏语言与蓝图

游戏显示语言与配音语言独立，从工程语言生成；单语言作品会隐藏相应选项。Studio 界面语言和译稿校对语言另属编辑器设置，不为找回隐藏项改造作品。

蓝图自动排列和连线曲线／直角样式只改变画布呈现。保留节点、连线、跳转和调度关系；排布任务不授权改剧情。界面动作能否由 MCP 执行，查当前 schema，不根据按钮存在推定工具存在。

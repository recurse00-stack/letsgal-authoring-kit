# 当前能力索引

适用 **2.8.0-beta.1**。本页负责选择专题；实际字段以当前 MCP schema、目标 SDK 和保存样本为准。这里登记了制作方法，不表示这些能力在当前作品中均已验收。

| 任务 | 专题与重点 |
| --- | --- |
| 剧情、变量、蓝图 | [剧情与配音](story-and-voice.md#剧情变量与流程)：调用返回、调度、变量范围和新判断点 |
| 翻译、配音、识别 | [剧情与配音](story-and-voice.md#本地化与语音识别)：稳定行 ID、源哈希、语言覆盖和识别队列 |
| 立绘、动态图像、场景、音视频 | [素材与舞台](stage-and-assets.md)：登记、引用、运动和效果清理 |
| 演出时间轴 | [演出段](performance.md)：时间单位、允许块、连续播放和重播副作用 |
| UI、主题、数据库 | [UI 与数据](ui-and-data.md)：文档与槽位、真实点击、数据消费者和恢复 |
| 预览、调试、导出 | [预览与构建](preview-and-build.md)：实际到达位置、选择交互、构建终态与运行产物 |
| 扩展 | [扩展开发](extensions.md)：参数检查、双入口、SDK 与持久化 |

## 当前已知边界

- 普通扩展参数未被所有入口完整校验；写入前按声明检查，见[参数与校验](extensions.md#参数与校验)。
- 语音模型 ready 不保证识别能启动；持续 BUSY 的有限排查见[本地化与语音识别](story-and-voice.md#本地化与语音识别)。
- 一类数据行撤销曾报告成功却未恢复原 ID；恢复必须读回，见[数据表](ui-and-data.md#数据表的编辑与运行)。
- 高级调度等待选章时，调试启动不保证能定位指定章；按[预览范围](preview-and-build.md#预览范围)核实际 cursor。

这些结论都有对象和版本范围，不扩展为所有工程必现，也不按出现于协作房间就归为多人限制。宿主实测记录随发行包单独保存；同版本证据可复用，未知新版先重新核对受影响合同。

# 当前能力与制作指引 · Beta 2.7.1-beta.1

当前维护目标只有 **2.7.1-beta.1 / beta**。2026-10-13读取[Beta清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-beta.json)确认；完整版本、工具能力及授权分别核对。旧版和冲突按[版本边界](version-compatibility.md)标 UNKNOWN，无版本依赖工作继续。推荐官方 MCP，执行细节集中在[MCP工作流](mcp-workflow.md)；未接入时简短提示一次，再按获准原生／合法离线流程或草稿继续。

本页融合当前仍适用的基础与 Beta 能力，不要求依次读取历次公告。正式版网页作基础，Beta 公告补充差异；实际写入用当前 schema、SDK 或目标保存样本，不把公告当字段定义。

## 剧情与变量

从目标章节、片段和相邻区块开始，不为局部对白加载全工程。保留富文本、停顿、变量标记、稳定 ID 和演出参数；已录音频不会随改字自动更新。[制作](production.md)说明讨论、委托、部分采用及完成条件，[JSON](json.md)说明有字段依据时的结构处理。

选项跳转与仅赋值分开：使用当前保存样本／schema 确认 `mode`、`varOps`、返回位置；“加 1”不是“设为 1”。`slot` 等变量作用域、初始值、重置时机及存档效果按当前实例确认。修改分支检查每条受影响路线、变量值和回流；仅看到插值文本不证明控制流正确。译稿保持原文 Block ID、占位符和人工译文，校对语言与游戏启动语言分别设置。

If 是一次条件判断，不是持续监听。[官方说明](https://docs.avg-engine.com/manual/writing/blocks/if/)指出回放／历史跳转会复用既有判断；查询方法不应依赖回放必定重做副作用。需要在新位置按新值判断时，建立独立判断块与新 ID，保留原块；不要猜缓存字段或复制同一 ID。`main` 调用的文档存在冲突，已有调用不直接判损坏，新内容优先普通、无环片段；不依赖递归菜单或未经目标版本确认的展开深度。

## 多语言配音

2.7.1 的常规多语言配音只需给对白／旁白绑定原声：同一语音表键对应各语言录音，游戏按玩家的配音语言选同键文件，缺失时回退原声。先核原声语言、语音表键、角色、稳定 Block ID 与录音；不要把自动对应改成每句每种语言重复绑定。译文、录音、游戏显示语言与 Studio 界面语言各自维护，改译文不会生成录音。

当前 `voice_edit` 声明中，`assign_locale` 标记音频语言，null 为原声；`set_voice_key` 设置对照键，null 时从文件路径推导（去掉音频自身语言目录和扩展名）。语言标记和语音键不等于对白已经绑定。

`set_line_audio`／`clear_line_audio`／`auto_match` 省略 `locale` 时处理原声；指定 `locale` 时操作该句的语言覆盖，优先于语音表。只在确需单句例外时设置覆盖，并保留其他语言。清除指定语言只移除覆盖，该句重新按语音表／原声回退，不等于静音；清除绑定不删除录音文件。

`auto_match` 先 `dryRun` 审查候选和影响行，应用带返回的 `baseRevisions`。目标语言匹配会跳过语音表已有对应的行，依据该语言音频及有效译文；缺少最新译文的行保持未匹配，不补猜内容或强行覆盖。匹配只处理目标角色／行，不把相似文件名当作通过。

按作品需要在原声、目标语言、缺失语言录音、单句覆盖及移除覆盖后核对实际播放和回退。声明与工具读回不等于播放器通过；写入结构仍查当前 schema／官方专题，不依据公告猜 JSON 字段。

## 游戏语言与蓝图

- 游戏设置页可分别切换显示语言和配音语言，选项从工程语言生成；单语言作品隐藏相应两行。它们与 Studio 界面语言、译稿校对语言不同；不要为找回隐藏选项改造单语言作品。调整游戏设置或自定义界面时先核工程语言及实际工具／原生字段，再检查显示、声音与回退。
- 蓝图自动排列按剧情顺序分层，连线自动避让，可在“布局与方案”切换曲线或直角连线。排布和线型只处理画布呈现，不作为改变跳转、条件、章节顺序或调度模式的授权；保留现有节点与连线关系，确认改动范围及实际布局。

## 演出与素材

- **角色与模型**：区分素材库登记、角色表情引用、皮肤／姿势／部位及对白头像。先核资源、层序、默认值和逐句覆盖；不要为排错删除备用头像、清空主题或把动态图集改成静态图。Spine 核骨骼、Atlas、纹理和运行时；Live2D 核 model3 及依赖，Core／构建授权按官方流程在构建电脑处理，不随 Skill 分发。
- **行内超链接**：对白／旁白中的可点击文字可打开网页、界面或调用扩展方法，见[官方功能说明](https://docs.avg-engine.com/updates/2-5-0)。保留原行内格式和动作参数，使用实际目标 UI／方法 ID；从当前工具或原生保存样本取得结构，不猜 link 字段。它与独立的“打开外部链接”区块不同；检查实际点击效果及是否意外推进剧情，旧版有限点击记录不证明当前全部动作通过。
- **背景建场景**：多张背景是合成一个多层场景，还是每张分别建场景，按本次意图选择。保留素材来源与层顺序，核名称、尺寸、位置及剧情引用；导入图片不等于已创建或引用场景。具体入口见[场景管理](https://docs.avg-engine.com/manual/creating/scenes/)。
- **浮字**：文案、目标 ID、等待、停留和历史收录各自配置。地点牌可编排为“显示 → 两句剧情 → 按同一 ID 隐藏 → 确认剧情”；无限停留须允许剧情继续。空 ID 可能隐藏全部浮字，移除单条时指定原 ID。基础手册“阻塞”和部分界面“等待结束”不要直接当作同名 JSON 字段。
- **界面与音频**：按目标查对话框整体／分层动画、等待输入、消息文字、列表参数、点击穿透和声音分类。穿透不能误推进剧情，列表参数应对应真实对象；单轨、分类、全局与试听音量分别核对。系统说话人显示不替代作品业务状态，存档动画不证明槽位数据已改变。
- **素材制作**：预制包、差分调色、PSD 预检、网格轮廓／动作／时间轴、封面及缩略图按实际入口配置。模型库导入成功不代表角色与玩家都能显示。素材撤销不保证恢复外部磁盘文件，改删素材另核恢复覆盖和授权。

具体对象入口：[角色](https://docs.avg-engine.com/manual/creating/characters/)、[动态图像](https://docs.avg-engine.com/manual/creating/dynamic-visuals)、[浮字](https://docs.avg-engine.com/manual/writing/blocks/floating-text)、[译稿校对](https://docs.avg-engine.com/manual/writing/localization)。官方网页主要提供正式版基础，Beta 新参数以当前工具 schema、SDK 或原生保存样本补足；公告按钮名称不构成写入字段依据。

## 预览与导出

先核当前入口及“继承前文／继承上文”与局部预览。继承会从故事起点快进，并按默认选择经过前文；局部预览不等于正式开场状态。跨章 BGM、粒子、镜头、幕布或角色残留，先比较入口和前置剧情，不为局部画面批量删持续资源或给所有章加清理指令。原生预览、独立玩家、存读档和平台构建分别判断；API 线性展开也不证明高级分支实际可达。

实时预览到章末以右上角小胶囊提示，不再横跨底部遮挡对话框。按实际章节调度决定后续，不把提示位置或样式当作完整路线通过，也不为继续预览修改章节顺序。

剧本导出有纯文本、CSV、JSON、Ren’Py、Markdown、Word；与“导出章节”迁移文件、可运行游戏构建是不同交付。核章节、指令筛选、语言、预览、跳过项、数量及保存位置，不只看提醒计数。导出 JSON 可能带专用外层包装，不能整份当原章节写回；Ren’Py 只转兼容指令，不承诺完整游戏或无损回导。发布前按目标格式检查正文、角色、选项、占位符与编码，运行验证按作品要求安排。

缺资源构建错误从引用和合法素材恢复开始，不删除剧情来消除报错；平台依赖、路径、下载完整性和构建日志按[构建手册](https://docs.avg-engine.com/manual/overview/build)核对。更新 Skill 不会重建已导出游戏、升级引擎或发布作品。

2.7 公告说明已修复导出游戏偶发丢失 Steam 设置；已有构建需重新构建才能包含运行时修复。使用 Steam 的作品另核实际构建中的配置和成就行为，只有重建成功不等于平台集成通过。

创作者账号统计和玩家运营统计分开。只有作品需要时才依[游戏统计手册](https://docs.avg-engine.com/manual/overview/game-stats)配置：正式构建游戏与 Studio／localhost 预览范围不同，首次事件统计不是完整执行轨迹。“另存为”、密钥换新或关闭统计影响既有游戏，须有对应授权；不要编造上传 API 或公开实际账号／玩家数据。

## 扩展开发

先读[扩展专题](extensions.md)，核目标工程生成的 SDK 来源、版本、源码入口和当前接口；只在使用扩展时读取，不作为普通改字前置。程序扩展与纯界面扩展、UI 预览与剧情方法分别验证。保留官方生成 ID，按真实 package.json 构建脚本运行，不假设总有 dev；不直接改生成 dist。

历史追加、共享数据、方法参数、调度和存档都按当前 SDK 契约工作；追加一条可见历史不保证退出后恢复。数组更新、订阅清理、React 依赖及共享状态权威见扩展专题。SDK 声明、构建成功、宿主加载、方法执行和玩家保存是不同证据，按本次改动完成必要验证即可。

### 2.7 SDK 的具体用法边界

- 方法的 `inspectorLayout` 只组织编辑期表单，`schema` 仍平铺传给 `run`。`tabs` 与顶层 `groups` 二选一；组的 `fields`／`summaryFields` 引用原字段。预设的 `settingsKey` 对应 array 设置，行字段为 `id`／`name`／`paramsJson`；`preserveFields` 控制应用预设时保留哪些当前值，不改变保存整套参数的行为。先核目标 SDK，保留旧方法 ID 与参数，不为分组改变运行数据。
- `ctx.character.getStagePlacement(id)` 读取舞台立绘快照，React 中用 `ctx.character.useStagePlacement(id)` 跟随更新。未上场返回 `null`，隐藏状态看 `visible`；精确舞台目标离场后不转向另一层同角色。坐标是扩展 UI 视口像素，使用 `viewport`、`localBounds` 和仿射 `transform`，不能直接当窗口 CSS 像素。
- `ctx.flow.isRestoring` 表示当前是否在重建存档／快照执行路径。读档可能重入等待子片段的父方法；已随档保存的结算要避免重复，但仍须调用 `callFragment` 恢复子片段。最深落点恢复后标记立即改变，不能缓存成整个方法的固定状态；普通运行、快进、调试定位不是恢复，JavaScript 局部变量也不会随档恢复。引入此标记不证明既有插件的存读档问题已修复，需验证相应父子片段和保存位置。

以上四份相关 SDK 声明在 2.7.1-beta.1 与 2.7.0-beta.1 逐字节一致，版本常量已更新；静态一致尚不是本版运行验收；不会自动升级旧插件 SDK 或修改暂停中的插件。

## 当前其他能力与排错

2.7.1 公告涉及界面按钮卡顿、图片按钮悬停／按下闪烁、快速存档工具栏回跳、界面加载时机及自定义存档截图。只对受影响的具体界面检查；自定义存档需核截图是否包含存档窗口自身。显示／隐藏扩展界面的卡片名称改进不改变界面 ID 与引用。已有导出游戏需重新构建才能包含本次运行时改动，再检查目标平台的实际功能。

| 当前官方公告的主题 | 制作时怎样使用 |
| --- | --- |
| 官方本机 MCP | 读取当前服务指导和 schema，按工程、真实 ID、revision 与权限操作；不固定工具数量、不自动全开权限 |
| 复合搜索、角色／场景／图像／音频筛选 | 缩小目标范围；替换前审查当前命中，保留干扰项，不能沿用旧 revision 的搜索结果 |
| 行内镜头预设与标签、浮字预设 | 复用当前工程预设，核作用目标及参数；预设名不等于已知 JSON 结构 |
| Live2D 开关组和自定义参数 | 核模型实际支持项、默认值与角色引用；UI 设置、模型展示和玩家行为分别看 |
| 独立关闭对话框、行内等待输入、音乐暂停／恢复 | 区分隐藏、关闭、等待和继续的具体语义；不把暂停写成停止，不误删原演出 |
| 头像裁切／缩略图／静态回退、表情与资源多选 | 排查原引用和派生资源；批量改动只覆盖选中项，不以修复公告为由清空旧配置 |
| 网格形状选择与 800% 画布、语言／工具栏调整 | 属于当前编辑器能力；MCP 未覆盖时仅在获准且工具可用的情况下操作界面 |
| Android SDK 镜像／完整性／回退，Windows 缓存与崩溃诊断 | 按实际构建错误核依赖和日志，不自动修改全局网络或清理未知缓存 |
| 表达式／CSS 隔离校验、扩展资料入口修复 | 按当前诊断和 SDK 定位，不因此重写未知字段或相信所有旧问题均已消失 |

2.7 的问题检查修正了部分角色属性／扩展变量误报，旧名引用改为提醒。遇到诊断先核实际定义、稳定引用和旧名，不为消除提示删除变量或改写剧情。代码视图已公告修复注释丢失与立绘上下场并入对白，但仍按当前 `textRoundTripSafe` 和实际读回保护原结构；场景排序、动态头像、镜头位置、旋转与字体登记修复也只针对受影响对象核验。

Windows 更新器已公告修复安装位置、自身进程和日志问题；这不是所有机器的升级流程均已通过。沿用所在项目已确认的更新／恢复入口，出现失败先保全日志和事务，不自动重试未知结果、替换安装路径或更改权限。Studio 界面新增语言与作品译文／配音独立；Tab 人物类别按当前界面点击切换。

## 适用证据与限制

本轮核对 2.7.1-beta.1 官方公告、相关随包 SDK 指纹、当前 voice_edit 声明及只读状态返回；未调用工程读写或新增功能验收。旧 2.6.0-beta.1 的 MCP 指导与有限隔离编辑、2.5.0 的 If 重入、早期循环与历史追加记录继续保留原版本范围，不能当成 2.7 的播放器、存档或导出通过。

字段和能力缺口只阻塞依赖它的操作。对现有内容采用范围授权和至少一种有效恢复保护，见[安全边界](safety.md)；只读、拒绝、待批准或关闭的工具组不能改用界面／磁盘绕过。

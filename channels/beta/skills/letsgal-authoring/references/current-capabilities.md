# 资料与证据索引 · Beta 2.8.0-beta.1

本路径供版本检查脚本选择资料；任务路由见[主入口](../SKILL.md#按当前任务读取)，不必再加载一份重复目录。实际字段以当前 MCP schema、目标 SDK 和保存样本为准，资料存在不表示当前作品已经验收。

## 当前已知边界

- 普通扩展参数未被所有入口完整校验；写入前按声明检查，见[参数与校验](extensions.md#参数与校验)。
- 语音模型 ready 不保证识别能启动；持续 BUSY 的有限排查见[本地化与语音识别](story-and-voice.md#本地化与语音识别)。
- 一类数据行撤销曾报告成功却未恢复原 ID；恢复必须读回，见[数据表](ui-and-data.md#数据表的编辑与运行)。
- 高级调度等待选章时，调试启动不保证能定位指定章；按[预览范围](preview-and-build.md#预览范围)核实际 cursor。

这些结论都有对象和版本范围，不扩展为所有工程必现，也不按出现于协作房间就归为多人限制。宿主实测记录随发行包单独保存；同版本证据可复用，未知新版先重新核对受影响合同。

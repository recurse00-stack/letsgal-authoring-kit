# Beta 当前维护边界

本载荷登记 **2.9.0-beta.1／2.8.0-beta.1**，Skill 发行号为 0.2.9。历史证据未记录完整热修复身份；首次工程操作需补核或取得当前使用者对该未知范围的一次明确许可，随后缓存复用。3.0.0 选择 Stable 载荷，即使引擎更新偏好选了 Beta。

## 低频静默开工检查

纯讨论、资料整理和未接入工程的草稿不触发。首次对目标实例执行工程／扩展调用、预览或构建前，复用本来就要读取的 `studio_get_status`，取得实际完整版本；同时核已有的热修复标识。正常匹配静默继续，不额外汇报、不启动浏览器、不默认联网、不扫描 SDK 或整个安装目录。

只在当前任务上下文缓存：目标实例／端点、project.id、Skill 修订、完整宿主版本、热修复标识及已知哈希、项目明确固定的引擎目标、检查结果和本次例外范围。同一有效组合直接复用，不每轮对话、每次工具调用或每个章节重复检查，也不设置定时轮询。

已知升级／热更、目标实例重启或重连、换工程、Skill 修订变化、来源冲突或接口不符时，顺带刷新相关身份并比较；身份未变且授权仍覆盖任务时继续复用，不重新询问。普通剧情 revision 变化不使版本检查失效。上下文丢失时只补读身份，不重做全套研究。

## 分清版本来源

完整版本、界面热修复和“更新通道”是三件事。例如 `3.0.0`、`3.0.0-stable-r2` 与更新设置选 Beta 可以同时存在；更新通道决定以后接收什么更新，不能据此改写当前版本或选择 Beta Skill。官方最新清单也不能代替本机当前实例。

热修复优先取当前实例已提供的标识；工具未提供时，只读已确认属于同一安装的官方小型元数据。Windows 已观察到用户数据目录 `letsgal-studio/renderer-patch/current.json`，含 baseVersion、channel、rev、sha256。这是安装标记，需确认对应目标实例且没有待应用／来源冲突；远程 MCP 不读取本机标记充当证据。未知字段保持未知，不把缺标记当 r0。无需为这一步抢前台或反复重连。

## 不匹配与本次例外

完整版本未登记、热修复不同、同标识却哈希不同，或热修复无法确认时，暂停该目标的写入、预览运行、构建和其他版本相关执行；继续讨论、草稿以及只读身份／接口核对。向**当前使用者**一次说明实际版本／热修复、维护基线、可能的接口差异和拟执行范围，询问是否允许本次在该组合上继续。没有明确回答就保持暂停，普通“继续”及以前对其他版本的许可不替代此次同意。拒绝后同一任务不反复询问。

获得明确同意后，在当前任务记录对应组合与范围，按当前 schema、样本和必要 dry-run 进行最小操作，写后读回。例外不把未知版本登记成已验证兼容，不跳过宿主确认，也不扩展到别的工程／版本／任务范围。来源相互冲突或连错实例时先定位目标；不能用例外许可掩盖工程身份不明。

这里暂停的是目标工程操作；不卸载、不关闭全局 Skill，不自动切换或升级引擎，也不自动联系 Skill 作者或引擎官方。

## 检查命令

`scripts/inspect_version.py` 保留原参数、JSON 字段与资料路由退出码。默认 `reference_selected`／0 只表示选到参考资料；`UNKNOWN`／2 表示路由未确定。**执行工程操作要看新增 `operation_gate`，或加 `--gate`**：matched／0 可继续；confirmation_required／2 等本次明确同意；identity_required／2 先补足或消除身份冲突。脚本只比较证据，不联网、不写缓存、不授予例外权限。

- `--patch-id`：来自当前目标的热修复标识；有哈希时可传 `--patch-sha256`。
- `--renderer-patch`：已确认属于本机目标的官方 current.json；不会自动猜远程目录。
- `--update-channel`：仅记录更新偏好，不影响匹配；原 `--channel` 仍指宿主版本发布通道。
- `--project-version`：只填作品明确固定的目标引擎版本；作品自己的发行号不填此处。

识别码不足或来源冲突时先用已有只读入口补证；确需查新版本时再看[正式清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-stable.json)、[Beta 清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-beta.json)和对应官方契约。联网不可用不触发循环重试。

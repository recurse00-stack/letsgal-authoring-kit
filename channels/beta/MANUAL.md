# Beta 通道指南



本版 **2.9.1 / 20261113-optional-wiki**，主要目标 Studio **2.9 Beta**，保留 **2.8 Beta** 兼容路线。安装时选 `beta`，技能名仍为 letsgal-authoring，同一目录只装一份。共同使用方法见[总目录](../../MANUAL.md)和[完整离线手册](../../MANUAL.html)。



## 本通道差异



2.9 使用嵌套选项／条件，2.8 按对应旧结构指导。翻译写入逐条判断拒绝结果；else 不携额外条件。个人偏好、插件指南、未知写入结果和精确恢复采用通用规则；3.0 的工程打开接口、跨章行为和 SDK 新字段不套用到 Beta。历史观察见 [Wiki 自测记录](../../docs/wiki/07-recovery.md#本项目自测问题历史)。



按主次版本与实际发行身份检查，同系列补丁与热修复不单独暂停；超出维护／兼容系列时由当前使用者确认本次范围。身份不明先核对，讨论与草稿可以继续。2.5 资料和旧安装包在[历史发行](https://github.com/recurse00-stack/letsgal-authoring-kit/releases)。

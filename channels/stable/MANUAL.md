# 正式版 通道指南

本版 **3.0.1 / 20261112-r5**，目标 Studio **3.0 系列正式版**。安装时选 `stable`，技能名仍为 letsgal-authoring，同一目录只装一份。共同使用方法见[总目录](../../MANUAL.md)和[完整离线手册](../../MANUAL.html)。

## 本通道差异

支持当前 MCP 工作流。studio_open_project 会切换本窗口已有工程，需要独立窗口时使用对应界面入口；旧 branch 的跨章规则与普通片段调用不同。SDK 新字段按 3.0 类型使用。设置 reset、调度撤销及文件会话的历史现象与 r5 复测结果见[排错与恢复](../../docs/wiki/07-recovery.md)。

按主次版本与实际发行身份检查，同系列补丁与热修复不单独暂停；超出维护／兼容系列时由当前使用者确认本次范围。身份不明先核对，讨论与草稿可以继续。2.5 资料和旧安装包在[历史发行](https://github.com/recurse00-stack/letsgal-authoring-kit/releases)。

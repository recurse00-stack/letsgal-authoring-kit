# 本任务临时文件清单

仅复制到本任务现有持久记录中使用，不把示例当真实文件，也不要求每个普通创作任务建此表。

- 任务／授权范围：待填
- 工程 ID、绝对根、宿主版本：待核（不要用软件安装目录代替工程根）
- 可关闭时机及最后核对时间：待核

未知项如实保留，不把示例hash或“未发现引用”伪装成实际校验。原有复用文件记确定保留；本轮inbox输入另列。漏记项据历史补录并标来源。已删除／原已不存在仍须完成必要读回；等待关闭、证据不足、失败不能计入已完成。

收尾保留一份准确清单及必要恢复入口，清理无用途的重复记录；唯一恢复副本不随普通暂存清掉。流程见[临时素材清理](../references/asset-cleanup.md)。

# 当前能力与制作指引 · 正式版 2.5.0

当前维护目标只有 **2.5.0 / stable**。2026-10-10读取[正式版清单](https://static-lg-studio.cn-gd.ufileos.com/studio/latest-stable.json)确认；这不是对本机安装或全部功能的新验收。旧版和冲突按[版本边界](version-compatibility.md)标 UNKNOWN，无版本依赖工作继续。操作走[原生／离线流程](file-workflow.md)。

本页融合仍适用的能力，按任务阅读下面一节即可，无需按旧版发布时间逐页拼接。当前版功能依据官方正式公告、基础手册及注明版本的有限观察；字段以目标样本为准。

## 剧情与变量

从目标章节、片段和相邻区块开始，不为局部对白加载全工程。保留富文本、停顿、变量标记、稳定 ID 和演出参数；已录音频不会随改字自动更新。[制作](production.md)说明讨论、委托、部分采用及完成条件，[JSON](json.md)说明有字段依据时的结构处理。

选项跳转与仅赋值分开：使用当前保存样本／schema 确认 `mode`、`varOps`、返回位置；“加 1”不是“设为 1”。`slot` 等变量作用域、初始值、重置时机及存档效果按当前实例确认。修改分支检查每条受影响路线、变量值和回流；仅看到插值文本不证明控制流正确。译稿保持原文 Block ID、占位符和人工译文，校对语言与游戏启动语言分别设置。

If 是一次条件判断，不是持续监听。[官方说明](https://docs.avg-engine.com/manual/writing/blocks/if/)指出回放／历史跳转会复用既有判断；查询方法不应依赖回放必定重做副作用。需要在新位置按新值判断时，建立独立判断块与新 ID，保留原块；不要猜缓存字段或复制同一 ID。`main` 调用的文档存在冲突，已有调用不直接判损坏，新内容优先普通、无环片段；不依赖递归菜单或未经目标版本确认的展开深度。

## 演出与素材

- **角色与模型**：区分素材库登记、角色表情引用、皮肤／姿势／部位及对白头像。先核资源、层序、默认值和逐句覆盖；不要为排错删除备用头像、清空主题或把动态图集改成静态图。Spine 核骨骼、Atlas、纹理和运行时；Live2D 核 model3 及依赖，Core／构建授权按官方流程在构建电脑处理，不随 Skill 分发。
- **行内超链接**：对白／旁白中的可点击文字可打开网页、界面或调用扩展方法，见[官方功能说明](https://docs.avg-engine.com/updates/2-5-0)。保留原行内格式和动作参数，使用实际目标 UI／方法 ID；从当前工具或原生保存样本取得结构，不猜 link 字段。它与独立的“打开外部链接”区块不同；检查实际点击效果及是否意外推进剧情，旧版有限点击记录不证明当前全部动作通过。
- **背景建场景**：多张背景是合成一个多层场景，还是每张分别建场景，按本次意图选择。保留素材来源与层顺序，核名称、尺寸、位置及剧情引用；导入图片不等于已创建或引用场景。具体入口见[场景管理](https://docs.avg-engine.com/manual/creating/scenes/)。
- **浮字**：文案、目标 ID、等待、停留和历史收录各自配置。地点牌可编排为“显示 → 两句剧情 → 按同一 ID 隐藏 → 确认剧情”；无限停留须允许剧情继续。空 ID 可能隐藏全部浮字，移除单条时指定原 ID。基础手册“阻塞”和部分界面“等待结束”不要直接当作同名 JSON 字段。
- **界面与音频**：按目标查对话框整体／分层动画、等待输入、消息文字、列表参数、点击穿透和声音分类。穿透不能误推进剧情，列表参数应对应真实对象；单轨、分类、全局与试听音量分别核对。系统说话人显示不替代作品业务状态，存档动画不证明槽位数据已改变。
- **素材制作**：预制包、差分调色、PSD 预检、网格轮廓／动作／时间轴、封面及缩略图按实际入口配置。模型库导入成功不代表角色与玩家都能显示。素材撤销不保证恢复外部磁盘文件，改删素材另核恢复覆盖和授权。

具体对象入口：[角色](https://docs.avg-engine.com/manual/creating/characters/)、[动态图像](https://docs.avg-engine.com/manual/creating/dynamic-visuals)、[浮字](https://docs.avg-engine.com/manual/writing/blocks/floating-text)、[译稿校对](https://docs.avg-engine.com/manual/writing/localization)。官方网页主要提供正式版基础，Beta 新参数以当前工具 schema、SDK 或原生保存样本补足；公告按钮名称不构成写入字段依据。

## 预览与导出

先核当前入口及“继承前文／继承上文”与局部预览。继承会从故事起点快进，并按默认选择经过前文；局部预览不等于正式开场状态。跨章 BGM、粒子、镜头、幕布或角色残留，先比较入口和前置剧情，不为局部画面批量删持续资源或给所有章加清理指令。原生预览、独立玩家、存读档和平台构建分别判断；API 线性展开也不证明高级分支实际可达。

剧本导出有纯文本、CSV、JSON、Ren’Py、Markdown、Word；与“导出章节”迁移文件、可运行游戏构建是不同交付。核章节、指令筛选、语言、预览、跳过项、数量及保存位置，不只看提醒计数。导出 JSON 可能带专用外层包装，不能整份当原章节写回；Ren’Py 只转兼容指令，不承诺完整游戏或无损回导。发布前按目标格式检查正文、角色、选项、占位符与编码，运行验证按作品要求安排。

缺资源构建错误从引用和合法素材恢复开始，不删除剧情来消除报错；平台依赖、路径、下载完整性和构建日志按[构建手册](https://docs.avg-engine.com/manual/overview/build)核对。更新 Skill 不会重建已导出游戏、升级引擎或发布作品。

创作者账号统计和玩家运营统计分开。只有作品需要时才依[游戏统计手册](https://docs.avg-engine.com/manual/overview/game-stats)配置：正式构建游戏与 Studio／localhost 预览范围不同，首次事件统计不是完整执行轨迹。“另存为”、密钥换新或关闭统计影响既有游戏，须有对应授权；不要编造上传 API 或公开实际账号／玩家数据。

## 扩展开发

先读[扩展专题](extensions.md)，核目标工程生成的 SDK 来源、版本、源码入口和当前接口；只在使用扩展时读取，不作为普通改字前置。程序扩展与纯界面扩展、UI 预览与剧情方法分别验证。保留官方生成 ID，按真实 package.json 构建脚本运行，不假设总有 dev；不直接改生成 dist。

历史追加、共享数据、方法参数、调度和存档都按当前 SDK 契约工作；追加一条可见历史不保证退出后恢复。数组更新、订阅清理、React 依赖及共享状态权威见扩展专题。SDK 声明、构建成功、宿主加载、方法执行和玩家保存是不同证据，按本次改动完成必要验证即可。

## 适用证据与限制

2.5.0 的既有有限测试确认过预览继承变量、If 同块复用风险、一个无环 A→main 调用、两条基础路线及部分玩家／读档／导出；不证明所有路径。已观察 Ren’Py 跳过 endChapter 而提醒计数仍为 0，故导出时需查跳过项。新一轮只整理指引并检查交付，没有重跑宿主。旧 Beta 循环、历史 API 与模型案例不升级为正式版通过。

这些限制不阻止普通创作；只有依赖未确认行为的步骤才补证。工程修改前至少一种恢复保护，已有／采用／定稿内容须对应范围授权，见[安全边界](safety.md)。

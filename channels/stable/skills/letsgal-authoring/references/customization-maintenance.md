# 配置、迁移与本地特调

只在建立配置、迁移或维护 Skill 时读取；日常偏好选择见[个人定制](customization.md)。用户区独立于公共 Skill，安装／更新／卸载保留既有个人内容，插件知识不混入个人偏好。

需要新项目入口可用[项目模板](../templates/LETSGAL.example.md)，先读已有规则，再记录语言与文风、命名、素材布局、备份、Git 分支／提交习惯、平台、验证深度和交接位置；未决定项保持未定。安装技能不会自动写真实作品。

例如：“按这个项目建立配置，保留冲突待确认；记录文风、素材路径和验证目标，不修改公共技能或其他工程。”可用工具、MCP 注册与权限由实际客户端决定，项目说明不能添加能力。

旧偏好迁移须有明确委托：保全新旧两份原文，整理并核对关键约定，保留旧文件作为恢复材料并记录迁移事实。安装器不自动搬删旧 user.md，也不能建空白新文件遮住它。

仅适配一种工具时优先其用户／项目配置；不同本地客户端可明确共用配置，但 SSH、WSL、容器和云端各有自己的主目录，须将所需配置明确复制到目标环境，不能声称本机安装已同步。

明确要求改 Skill 本身时保全原版本、记录本地修改，让安装器正常检测差异。长期分叉可改独立名称并保留来源；同名公版与私版并装会有发现歧义，不为同步自动改其他客户端。

旧特调升级时比较旧 Skill、安装指纹与新包：个人习惯归 user.md、作品选择归 LETSGAL.md、通用修正另提候选。读回关键配置后才替换公共文件，原文留恢复副本；不明段落保留待判断，不总结后直接删除。

# Studio 3.5 正式版创作用法

## 演出和声音

要让道具、前景插画随镜头运动，并在一段演出中进出或位移，可选演出插图。它与立绘处于同一层，可在演出段内设置动画。需要文字自行消散时，先看浮动文字的退场动画和粒子预设。预览时连同人物遮挡、镜头运动与下一句的画面一起检查。

音频片段可裁剪、叠加效果预设、设置淡入淡出，换曲时可交替过渡。按目标区分单段裁剪、片段效果和两段之间的交替；用波形定位剪点，再试听切口与重叠处。工坊音效可试听并导入。涉及自动化写入时先从该版本的工具参考或目标工程样本取得实际字段、单位和素材引用，再沿[演出段](performance.md)流程读回。

### 宿主提供的块与字段

- 用 `showIllustration` 设置章内唯一的 `illustrationId` 和已导入图片路径。`cameraMode` 留空时随镜头运动，`pinned` 时固定在屏幕。用 `updateIllustration` 引用同名插图，只填要变更的属性。多张一起退场时，按 `removeIllustration` 的 `illustrationTargetsJson` 提供名字数组的 JSON 字符串。
- `sound` 绑定已导入资源的 `soundId`。使用已保存的剪辑时一并保留 `audioClipId` 与对应 URI。项目效果预设 `filterPresetId` 优先于内置 `filterPreset`。同一音轨换文件时，`crossfade` 的字符串值 `"true"` 让前后两首同时淡出、淡入；`fadeDuration` 以毫秒字符串填写，交替时留空使用 1000 毫秒。
- 浮动文字使用 `inPreset`、`outPreset` 指定进退场。雪花消散可选 `snow-dissolve`，碎片散开可选 `shard-scatter`。完整可选值从 `studio_get_reference(topic="blocks", blockType="floatingText")` 取得。

### 3.5.0 内嵌预览实测

插图以同一个名字显示、移动、退场。720 像素宽的截图里，标记从左侧 x=101～256 移至右侧 x=462～617，退场后标记像素归零。验收插图移动时可用固定背景比较前后位置。

在「资产 → BGM → 音频编辑器」新建片段，选择原音频后输入起止时间，点「保留选区」，再保存片段。本次将 4 秒的 440 Hz 音源截取第 1～3 秒，选用「水下」预设，设淡入 0.4 秒、淡出 0.6 秒。工程生成 2.00 秒的新 WAV，保留原文件。片段的配置记录起止和淡化的单位为秒；剧情 sound 块的换曲淡化按毫秒填写。引用时使用保存后的片段 ID、生成文件的 URI 和相应资源标识。样本在 Studio 剧情播放时测得约两秒的 440 Hz 输出。

同一 BGM 轨从 440 Hz 换至 880 Hz，开启交替过渡并设 1600 毫秒。进程输出中两种频率同时出现，旧声逐渐减弱、新声逐渐增强。

## 游戏壳、存档与回退

3.5 宿主的 `autoSave` 块没有作者参数。先启用游戏自动存档，它会在下一个安全剧情位置更新唯一的自动存档槽；读档重放时跳过触发。该块只支持块 JSON。修改含它的片段应保留原块和 ID，用块级操作或块 JSON；整段按脚本文本重写会失去这个无法表达的块。

调整选项、输入框、对话框、段落或存档时，从默认游戏壳查所属设置；内置界面选项的文字可自定义。玩家的自动存档、从历史记录回到某句对白、编辑器定时保存剧本分别服务于不同目的。验证玩家回退时，选取对白前后的变量或分支，回退后继续推进；验证自动存档时，从游戏的存档入口实际读取。

**自动存档实测（Windows 3.5.0）**　在「个性化 → 项目设置 → 游戏系统 → 存档设置」开启「游戏自动存档」。进入调试运行，自然推进过原生 autoSave 块，从游戏工具栏点「读档」，选择第一格自动档并确认。样本从值 30 读回 A 点的 20；第二个 autoSave 把同一格更新为 B，从值 40 读回 B 点的 30。局部剧本预览在同一工程开关已启用时返回空槽，判断玩家能否读档应走调试运行的游戏界面。

## 导出与旧样本

导出器会裁去未使用的场景、角色以及仅供它们使用的素材。涉及扩展运行时选取角色或场景的作品，用构建产物走一次对应分支，核对资源是否随包。该优化作用于导出产物，工程中的素材清理仍按[素材清理](asset-cleanup.md)处理。

官方列出了循环轨交叉淡化、重复调用片段的条件判断、快进时鉴赏解锁，以及切换存读档模式等修复。3.0 r7 的黑白读档差异在 Windows 3.5.0 内嵌预览仍能复现。扩展用 `ctx.flow.callFragment()` 进入子片段，在选项内黑白画面处存档，推进到彩色再读档：位置和变量恢复，镜头返回 grayscale、强度 1，实际画面在立即和延后截图中均为彩色。原生 callFragment 进入同一子片段则恢复黑白。对依赖这一画面的路线，可在条件允许时采用已验证的原生调用，并核对目标作品的读档截图。独立 Player 表现待验证。旧样本范围见[预览与构建](preview-and-build.md)。

## 更新工作台并保留挂载

用完整主包的安装器更新原有用户区。工作台从已登记的插件、附属包、个人资料、旧式 Wiki 清单和持久挂载的阅读资料生成本机手册。包的启停、固定版本及暂停展示按原登记执行。验收时从原工作台入口打开更新前可见的指南，用原书签或目录进入正文，并核对已暂停的包仍按原设置展示。

只有一份资料 JSON 时，在本机 `Open-Workbench.cmd` 中点「挂载资料」。直接打开发行包里的静态 HTML 时，「预览资料」只供本页阅读。挂载阅读资料不会给 AI 安装插件。挂载或更新报错时保留个人区和旧手册，按提示修正对应资料后重试。

功能与修复依据为 [Studio 官方发行历史](https://static-lg-studio.cn-gd.ufileos.com/studio/releases-history.json)中 3.5.0 条目。与宿主交互时以当前工具参考和工程样本确定可写范围。3.0 的接口与运行样本保存在[3.0 资料索引](current-capabilities.md)。

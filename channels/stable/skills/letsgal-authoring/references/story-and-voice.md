## 剧情、变量与流程

保留普通章顺序、前处理和高级调度的实际入口。被调用片段结束后返回，章末按调度进入后续；蓝图排布仅调整画布。

**3.0 新建**：使用 menu 的缩进选项及 if／elif／else 正文，支持嵌套，结束后回流组后剧情。空正文用 pass，调用片段用 call，变量操作用 $。首次写入读目标 script-syntax 的 Choices and conditions，存储标记和成组移动见 [JSON](json.md#引用与控制流)。

**旧块维护**：3.0 的 branch 选项可调用其他启用章节中唯一的片段并返回原处；旧 if 与普通 call／jump 仍限同章。先从完整 outline 核目标 ID、唯一性及章节启用状态，保留旧 ID、富文本及语言／配音关联。新建选项使用嵌套结构，不新造旧 branch。展开旧结构会改变存档路径，迁移前明确范围和验证。

变量核 key、类型、初值及槽位／共享／启动重置范围；分别检查读档、回标题和新启动。区分赋值、增量及旧选项的跳转／变量模式。变量分组只影响编辑组织，当前 var_edit 无分组写操作。

条件在执行点求值；旧 If 的复用风险按旧版本范围处理，需要新状态就设独立判断点。条件方法做查询，副作用用动作。callFragment 同章调用后返回，当前契约转换期最多展开 30 层；循环菜单按实际调度设计。

## 多语言配音

1. 绑定原声，核语音表相同 key 的各语言音频；缺目标语言时回退原声。
2. voice_edit.assign_locale 标音频语言，null 表示原声；set_voice_key=null 使用去掉语言目录和扩展名后的派生键。
3. 单句操作省略 locale 时处理原声槽；指定 locale 写逐句覆盖，优先于语音表。清除覆盖后恢复表匹配／原声回退。
4. 自动匹配先 dry run，带 baseRevisions，审阅命中、语音表匹配而跳过项及缺失项，保留已有录音。
5. 读回句子 ID、各语言绑定，试听目标语言和缺音频回退；译文与录音分别交付。

全工程拟声用 `voice_edit.apply_character_blip`，先限定角色及全工程／章节范围并 dry-run；默认保留录音，只有明确要替换录音时才设置 overwriteRecordings。

## 本地化与语音识别

l10n_read 按 config／rows／names／coverage 取目标范围。names 包含已登记角色显示名变体及手填说话人；UI、章节和游戏标题另查对应本地化入口。

写译文携带语言、稳定行 ID、源文哈希和当前状态，保留其他语言。l10n_write 的 set_translations 逐条返回 written／cleared／unchanged／rejected；SOURCE_CHANGED 是 entry 的拒绝原因，同批其他条目可能已成功。逐条读回结果，只对被拒条目重读源文和 sourceHash、重新翻译并提交，不把部分成功当整批失败或重复提交已成功项。

临时 preview_control.set_locale 前记录原语言；校对后恢复该值。恢复前核当前工程和值，保留用户后来设置。游戏显示语言、配音语言、Studio 界面语言和校对语言各按对应入口设置；单语言作品会隐藏相关游戏选项。

voice_transcribe 属于 advanced 工具组；缺席先核组与权限，不当作无配音能力。只提交本次素材，通过 asset_list(view="voice") 查进度和文本，完成后听音校对。2.9 样本本地识别完成；2.8 曾在模型 ready 后持续 BUSY。遇到 BUSY 查面板、队列和错误，有限重试后记录未完成，已有合法音频仍可直接绑定。cancel 会停止 Studio 当前所有识别任务，执行前核共享影响。

## 游戏语言与蓝图

语言设置按上节范围操作。蓝图自动排列及曲线／直角只改呈现，保留节点、连接、跳转和调度。需要界面动作时从当前 schema 确认 MCP 入口。

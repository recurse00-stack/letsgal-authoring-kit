# 修改范围与同步

## 对象归属

本次明确的章节／片段是内容修改边界。读取 outline 和原文取得真实 ID；追加前重新读取，保留协作期间插入的客串和未知块，不用任务开始时的整章副本覆盖现状。

UI、数据表、变量、角色、场景、素材和扩展属于工程共享对象。“我的章节”不自动授权修改这些定义。先查引用与实际影响：

- 引用获准使用的现有资源时，优先本章块级参数；不为一句演出改角色默认动作、公共布局、表情或素材文件。
- 任务确实包括新增共享资源时，用独立名称／ID并核授权范围；新 UI 不自动替换系统槽位，新表不自动成为运行数据源。
- 修改全局主题、语言、调度、构建或整工程恢复，应明确共享影响。仅为验证通用功能时，使用获准的隔离单机工程。

## 本地保存和远端收讫

写前看 userEditing、pendingSaves、lastSaveFailed，避免覆盖本客户端正在输入或尚未保存的内容。写后先读回目标，再看 collaboration 的 connection、unsynced、aligning、tooLarge、pendingDeletes 和 pendingLocalChanges。

online、计数归零、pendingLocalChanges=false 仅表示本客户端报告正常。另一成员是否收到正文、资源是否下载并能播放，需要远端证据；本机截图和新资源 hash 不能代替。没有第二客户端时记录缺口，不自动发消息或无限等人。

连接未就绪或仍在对齐时暂缓依赖同步的写入，有限等待后重读；持续异常保留草稿与具体状态，不通过清空内容、关闭协作或覆盖磁盘来消除计数。

## 预览与共同操作

在授权阅读范围内，预览他人内容无需改写其章节。预览会移动本地光标并执行内容中的效果，先了解待运行片段；不把它当纯静态读取或多人同步验收。

核实际预览章／片段／块，而不是只看编辑器选中项。被本机其他操作切换时，先协调必要的短暂连续操作窗口；只有当前实际画面可计入样例。位置回退原因未隔离时，不断言远端同步故障。

选择交互、演出中间帧、UI 点击与隐藏窗口的处理归母 Skill 的 `references/preview-and-build.md`、`references/performance.md` 和 `references/ui-and-data.md`；独立使用则查询当前 preview-testing／stage 指导。记录本次真正观察到的层次。

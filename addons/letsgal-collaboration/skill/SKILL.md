# LetsGal 多人协作

这是 Authoring Kit 的独立附加 Skill，适用证据为 **2.8.0-beta.1 有限内测**。不提供引擎、房间或 MCP；其他版本按实际状态与合同判断，不为了套用资料升级宿主。

## 先核范围，再执行

用 `studio_get_status` 确认工程 ID、版本、连接权限、协作及保存状态。复用当前任务已确认的本人身份和可写章节；只有缺失的信息才问。选中章节、MCP 可写或账号昵称均不能单独证明章节归属。

未进入房间时，由用户通过实际协作入口完成加入后再核状态；不寻找邀请密钥或猜加入接口。非协作工程直接按母 Skill 的普通制作流程。

| 当前任务 | 按需读取 |
| --- | --- |
| 决定可改哪些对象、引用共享资产、判断同步证据 | [范围与同步](references/scope-and-sync.md) |
| 局部编辑、冲突、占用、未知结果或恢复 | [MCP 与恢复](references/mcp.md) |

已有母 Skill 时复用其剧情、素材、演出、UI、预览和构建专题。独立使用时从当前宿主 quickstart 和相应专题取得制作合同；不能因未安装母包就猜字段。普通预览错误、音频识别、动画时序或数据撤销异常不自动归为多人限制。

## 完成条件

读回本次对象和 revision，核本地保存与同步状态，按作品实际变化验证预览。远端收讫必须有另一客户端或成员确认；没有证据就明确仅完成本地检查。

测试先限定目标、样例和停止条件。覆盖所需的文字、交互或媒体即可；不为覆盖率主动争抢行、断网、变更成员或构建共享作品。交接保留本次 opId、验证层次、未决项和恢复入口，不把成员信息、房间内容或私有章节带入公共例子。

# 适用版本与验证范围

附加 Skill 0.1.3；运行证据复用 0.1.2 及更早同宿主测试，未在本次文档重构中重跑；资料核对与实测日期 2026-10-20；宿主 **2.8.0-beta.1**。本次使用已经加入的多人内测工程，在获准的单一章节中完成有限验证。没有测试开房／加入／退出流程，也不宣称该功能已向所有账号开放。

| 能力 | 证据 |
| --- | --- |
| 本人身份、成员在线及正在编辑的提示 | 原生界面观察；MCP 同时返回连接与同步状态 |
| 他人片段阅读、分页与定位预览 | 实际读取及 `run_to` 到已知旁白；未提交他人章节写入 |
| 首轮文字写入 | 插入 14 块，原 1 个空块保留；首轮 15 块读回及编辑器可见 |
| 本轮保留并追加 | 追加前重读 20 块（已有新增客串），37 块演出尾声追加后原 20 块逐项不变；只修正本轮新块 |
| 引用共享演出素材 | 引用现有角色、场景、音视频与粒子贴图，没有修改共享定义或文件；新资产传输未测 |
| 演出验证的归属 | 静态立绘／Spine、转场／镜头、粒子、音视频状态与演出段做过有限预览；通用方法维护于母 Skill β，不作为多人专属能力或限制 |
| 修改与版本冲突 | 修改 1 个自建块；旧 revision 的 dry-run 成功，实际写入正确拒绝 |
| 局部撤销 | `history_undo` 预检及执行通过，整个自有片段恢复到临时修改前内容 |
| 编译／引用／条件／变量检查 | 片段检查 0 错误；2 条无跳转目标警告与有意汇合选项一致。片段级 flow 被跳过 |
| 两选项预览 | 两种回答分别选择后到同一结尾；并非两条不同剧情路线 |
| 保存与同步 | 本客户端 pendingSaves、unsynced、aligning、tooLarge、pendingDeletes 为 0，pendingLocalChanges 为 false |
| 远端收讫、同时争用同一行 | 未核验；没有第二受控客户端，未触碰别人占用的行 |
| 结构与受限操作 | 在本章实际新增独立片段通过；外部文件编辑、历史恢复预检返回 CHAPTER_LOCKED／COLLABORATION，未执行磁盘绕过 |
| 共享对象的独立测试 | 新建独立 UI、表、变量、角色、场景和测试素材，未绑定全局 UI 或改他人章节；本地读回不证明其他客户端收到 |
| 本轮恢复差异 | 剧情注释删除／撤销恢复原 ID；数据行撤销返回成功却未恢复，已以新 ID 重建测试行。原因不判为协作专属 |
| 断网重连、资产同步、成员管理、Player、存读档、导出 | 未测试 |

实测的瞬态现象：最初预览返回 WINDOW_HIDDEN，恢复窗口可见后通过；选项菜单曾在两次调用之间消失并回到跟随位置，有限重读／重定位后通过，根因未知。

演出观察和协作限制分开记录：预览跟随位置回退及切换章节曾使本例观察失效，有限重定位后到达目标；原因未隔离，不认定为多人协议故障。通用的字段层级、贴图和连续播放方法由母 Skill 修正，本包不重复维护。

资料权威：当前 Studio 返回的 `studio_get_status`、`studio://guide/quickstart`、errors、not-exposed、guide-preview-testing，以及 `studio://blocks/narration`、`studio://blocks/branch`。这些宿主资源不要求可通过公网打开；客户端不能读取 resource 时使用 `studio_get_reference`。

适配新引擎时应核对上述合同并重测受影响用例；同一未发布候选沿用发行号，下一次对外发行才递增。旧测试不能作为新版本已通过的证明；内测可用性、成员上限及权限不从本次在线人数推断。
